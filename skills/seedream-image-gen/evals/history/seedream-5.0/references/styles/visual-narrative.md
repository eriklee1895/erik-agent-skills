# 视频/叙事风格

适合：视频分镜设计、故事板、角色驱动的叙事插图、漫画/连环画、广告提案 mood board。

本 preset 提供的是**脚手架而非模具**：它默认使用多 panel 序列和电影化构图，但当用户 brief 已经带有强烈视觉概念时，模型应只保留结构 guardrails（panel 数量、角色一致性、叙事推进），让出风格自由。

Pro / Flash 的普通请求每次只返回一张图。独立分镜应逐场景调用，并复用角色/场景参考图；四格漫画等布局则是同一张图里的多个 panel。提示词中的“组图”“故事书”只是创作描述，不会启用原生多图返回。

## 结构模板（除非 brief 覆盖，否则保留）

| Guardrail | 默认 Prompt 关键词 |
|---|---|
| 媒介 | `电影级分镜`, `故事书模式`, `连环画`, `电影感概念图`, `角色设计图` |
| 背景 | `场景适配背景`, `多 panel 间环境一致` |
| 构图 | `单张图内[N]格`，或将 `[N]个场景` 拆成独立请求；`叙事推进`, `角色一致性`, `多景别切换`, `情绪弧线` |
| 硬约束 | `避免角色不一致`, `避免缺 panel 或多余 panel`, `避免过小看不清的文字（含文字时用 2K）`, `长段对白/旁白后期叠加`, `除非用户要求否则避免纯照片写实` |

## 灵感默认（当 brief 自带风格/氛围/配色时可被覆盖）

| 子风格 | 默认方向 |
|---|---|
| 电影级分镜 | `深邃星空背景`, `冷色调`, `侧逆光`, `紧张灾难氛围`, `舱内暖光与太空冷光对比` |
| 故事书模式 | `温暖柔和`, `绘本风格`, `四季/自然场景`, `明亮色彩` |
| 连环画/漫画 | `白底`, `黑色墨线轮廓`, `幽默漫画风格`, `中文对话气泡` |
| 电影感单帧 | `冷蓝与暖橙对比`, `王家卫电影感`, `史诗感`, `ultra-wide 21:9` |
| 角色设计/IP | `Pixar 3D`, `柔和工作室灯光`, `白底`, `多角度展示` |

> **覆盖规则：** 如果用户指定了不同的画风、配色或渲染风格，就放弃灵感默认，只保留结构模板（panel 数/序列、角色一致性、硬约束）。

## 1. 电影级分镜组图

电影分镜、多机位切换、连续性叙事。先规划场景，再为每个场景分别生成一张图；复用同一套角色和环境参考，并明确各参考图的用途。

**核心公式**:
```
电影级科幻/写实/...风格，生成单张分镜：[本场景描述]。[镜头与光线]。参考图1确定角色外观，参考图2确定场景；保持指定角色和环境细节，不要拼图。
```

**示例（先规划四个独立请求）**:
```
场景1：宇航员在空间站维修飞船，空间站外部精密机械结构，深邃星空背景，侧逆光勾勒轮廓，冷色调。
场景2：突然遇到陨石带袭击，广角史诗镜头，陨石高速袭来带燃烧尾焰，动态模糊，紧张灾难氛围。
场景3：宇航员紧急躲避，近景动态抓拍，失重状态下极速侧身躲避，背景陨石飞掠而过。
场景4：受伤后惊险逃回飞船，中近景，宇航员踉跄冲向开启的舱门，舱内暖光与太空冷光对比。
```

每次只将一个场景放入请求。场景1的完整提示词可写为：
```
电影级科幻写实风格，单张分镜。宇航员在空间站维修飞船，空间站外部精密机械结构，深邃星空背景，侧逆光勾勒轮廓，冷色调。保留参考图1中宇航员的头盔和宇航服，参考图2确定空间站外观。不要拼图。
```
使用 `--size 2K`；后续场景保留同样的参考图和角色细节约束。`--n` 只生成同一提示词的独立候选，不能替代逐场景请求。

**适用场景**: 视频分镜、电影提案、游戏概念设计

## 2. 故事书模式

连续故事插图、角色一致性、温暖叙事。“故事书”描述画风；独立页面需要分别调用，统一角色参考图和风格约束。

**核心公式**:
```
单张绘本插图，[本页剧情]，以参考图中的[角色]为主角，保留[关键外观]，温暖柔和的绘本风格，[本页构图]，不要拼图
```

**示例（五页故事大纲，拆成五个请求）**:
```
第1张：小狐狸在雪地里醒来，周围是冬天的枯树。
第2张：小狐狸穿过森林，发现第一朵盛开的花。
第3张：小狐狸在溪流边遇见一只兔子朋友。
第4张：两只小动物一起在花海里奔跑。
第5张：夕阳下，小狐狸和兔子坐在山坡上看春天全景。
```

第1页提示词：
```
单张绘本插图，参考图中的小狐狸在雪地里醒来，周围是冬天的枯树。保留小狐狸的橙色毛发、白色尾尖和绿色围巾，温暖柔和的绘本风格，低机位中景，不要拼图。
```
后续页面替换剧情和构图，复用同一张角色参考图；逐页检查一致性，不将其视为硬保证。

**适用场景**: 故事配图、品牌叙事、绘本创作

## 3. 连环画/漫画布局

4 格漫画、格子布局、对话气泡。适合轻量叙事、教程漫画化。

**核心公式**:
```
连环画风格，[N]格漫画布局，每格不同的剧情节点，角色统一，对话气泡使用中文
```

**示例（完整 preset）**:
```
连环画风格，4格漫画布局，展示一个程序员debug的心路历程：
格1"一切正常"（自信）→格2"等等这个报错"（困惑）→格3"StackOverflow也没有答案"（崩溃）→格4"原来少了一个分号"（顿悟）。
角色统一，幽默漫画风格，对话气泡使用中文，白底
```

**适用场景**: 教程漫画化、社交媒体短漫、团队内部幽默

## 4. 电影感单帧/概念图

ultra-wide 概念图、电影气氛图、游戏场景。适合视觉冲击力强的单张配图。

**核心公式**:
```
电影级/游戏概念艺术风格，[场景描述]，[镜头参数如广角/浅景深/特写]，[光影氛围]，ultra-wide构图
```

**示例（完整 preset）**:
```
游戏概念艺术风格，中世纪城堡废墟，晨雾缭绕，破碎的拱门下青苔覆盖的石阶，远处是被遗忘的王座，一束光线从天窗射入，广角构图，史诗感，冷色调
```

```
电影级都市夜景，上海外滩雨夜，霓虹灯倒映在湿漉漉的街道上，一个撑着透明伞的行人走过，浅景深，冷蓝与暖橙对比色调，王家卫电影感，ultra-wide 21:9
```

**适用场景**: 概念设计、气氛图、视觉冲击力强的单页插图

## 5. 角色设计/IP 图

Pixar 3D 角色、角色标准图、三视图。适合 IP 设计、品牌角色。

**核心公式**:
```
3D角色设计/Pixar风格，[角色描述]，多角度展示/标准pose，[风格细节]，柔和光线
```

**示例（完整 preset）**:
```
Pixar 3D动画风格，一只戴着圆框眼镜的橘猫博士角色设计，穿白色实验室外套，手拿试管，微笑表情，柔和的工作室灯光，角色设计图，白底，2K
```

**适用场景**: IP 形象设计、品牌角色、头像

## 视频/叙事通用技巧

1. **交付形态**: 多张独立分镜按场景分别请求；单张多格漫画明确格数和布局。Pro / Flash 不支持 `sequential_image_generation`、`max_images` 或流式组图。
2. **角色一致性**: 每个场景复用同样的角色参考图和关键外观描述，生成后检查肤色、体型、服装；参考图不能保证完全一致。
3. **多机位**: 描述景别变化（特写/中景/远景），增强叙事节奏感。
4. **情绪弧线**: 分镜设计注意情绪递进（平静→冲突→高潮→解决）。
5. **不要过度描述**: 每张分镜的描述控制在 2-3 句中文，让模型有发挥空间。
6. **章节标题/kicker 文字（Seedream 5.0 Pro）**: 电影感单帧、故事书封面、mood board 可在 2K 下嵌入 2-6 字的章节标题或 kicker——逐字写进 prompt 并用引号包裹，指定 bold serif 或 bold sans-serif 字体、字号和位置（如"画面顶部居中"、"左下角叠加大号白色衬线标题"）；多行对白、长段字幕、对话气泡多行排版仍建议后期叠加（[text-effects.md](text-effects.md)）。
7. **当用户 brief 已自带画风、配色或渲染风格时，放弃灵感默认，只保留结构 guardrails。**
