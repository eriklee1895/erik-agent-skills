# Seedance 2.5 系列提示词指南

适用于标准版与flash，共用[官方系列提示词指南](https://console.volcengine.com/ark/region:cn-beijing/docs/seedance-2-5-prompt-guide)（2026-11-15）。选择flash改变容量和输出上限，不改变提示词语法。参数约束见 [seedance-2.5.md](seedance-2.5.md)，场景示例与社区实践来源见 [scene-cookbook.md](scene-cookbook.md)。

## 1. 单镜头：直接描述可拍出的画面

按「主体＋动作/事件＋场景＋视觉风格＋运镜/切镜＋声音」组织，不需要的部分省略。4–5秒单动作不必强行拆镜或填写长模板。

```text
黄昏海岸，一只橘猫坐在木栈道上，缓慢转头看向海面。
低机位中景轻微推进，暖色逆光勾勒毛发。
只保留海浪与风声，无背景音乐，不要字幕。
```

首帧已给出主体外观时，prompt重点写动作、机位、光线变化与声音，少复述图中细节。首尾帧写两幅画面间合理的动作过程；跨度过大时增加时长或调整素材。

**长度建议**：[通用视频生成API教程](https://www.volcengine.com/docs/82379/1520757)建议中文≤500字、英文≤1000词；过长可能增加细节遗漏。系列指南同时强调减少参考内容的重复描述、控制每段事件密度。将最关键的主体、动作和约束放前面，不要求英文标签或固定段落全部出现。

## 2. 多镜头：绑定素材，再安排事件

基本结构为：**素材指代 → 一句话概述 → 具体情节（时间轴或镜头顺序）→ 全片约束**。按复杂度选用，不把每条短片都写成拍摄手册。

### 2.1 素材绑定与结构化示例

素材按各自类型的上传顺序编号，用`@图片1`、`@视频1`、`@音频1`在文本中指代；`@`不是API ID。CLI按每个对应参数出现的顺序构建素材列表。

```text
@图片1是主角的外观参考；@图片2只参考服装；@视频1只参考缓慢跟拍的运镜；
@音频1只参考主角音色。全片仅此一位主角，不新增人物。

一位旅行者在黄昏海边停下，发现随身相机里的旧照片，写实电影风格。

0-4秒：全景，旅行者沿栈道缓慢走来，夕阳从画面右侧照入。硬切。
4-9秒：中近景，她停下低头查看相机，轻声说：“原来你一直都在。”
9-12秒：切相机屏幕特写，显示一张海边旧照片，镜头停稳。

保持同一服装、光源方向和场景轴线。只生成海浪、脚步与对白，无bgm，不要额外字幕。
```

部分参考要同时写清**采用什么、排除什么**；冲突较多时可用自然语言列优先级，但它们不是专用控制词：

```text
不要复制@视频1的地点、服装、文字、人物或剧情，只复制身体节奏、手臂动作、
步行节奏和随身体联动的镜头运动。优先级：身体节奏 > 联动运镜 > 视角与环境。
```

参考视频已准确表达动作时，写「只参考@视频1的动作/运镜，顺序一致」，避免再用冲突的逐部位描述复述。多角色易错位时，按**首次出场顺序**上传并编号外观与音频素材，逐一映射角色、站位和声音。素材数量服从标准版30/10/10、flash10/5/5硬上限；官方稳定性区间见 [key-constraints.md](key-constraints.md#素材稳定性建议不是硬上限)。

需要明确职责时，可用以下标签组织：

| 标签 | 写什么 |
|---|---|
| GLOBAL STYLE | 题材、视觉风格、色调、全片约束 |
| SCENE | 一句话事件 |
| CHARACTERS / LOCATION | 主体映射、空间关系 |
| FIRST FRAME AND BLOCKING | 开场位置、朝向、站位 |
| Shot N | 每镜景别、机位、动作、反应、声音与衔接 |
| OPTICS / LIGHTING / PHYSICS | 有实际意义时再指定焦段、光源、材质运动 |
| AUDIO | 说话人、对白、环境音、音乐与音效 |

### 2.2 时间轴与切镜

两款模型均支持以**整数秒**描述事件；可用连续区间、时间点或相对时间，也可以直接写镜头序号。

- 连续区间：`0-3秒…3-7秒…7-12秒…`，不跳过未解释的时间段。
- 时间点：`第5秒切到俯拍全景`。
- 相对时间：`按下快门后定格1秒`。
- 不用时间戳控制高频动作次数，如「每秒摇头3次」。

每段安排足够完成的动作、反应与对白；内容过密会遗漏或过度剪切。写清动作先后、空间位置和表演节拍，不只写文学化剧情。时间戳帮助表达意图，不是逐帧剪辑保证。30秒可分成少量事件段，最后留稳定收尾。

需要切镜时写「硬切 / Hard cut」并描述新镜头的景别和对象；长镜头明确「一镜到底」和连续机位运动。`Hard cut`是自然语言组织方式，不是每个多镜prompt必须包含的控制符。不把「缓慢升起」与同段「固定机位」放在一起。

### 2.3 稳定性约束（named locks）

用简明正向约束明确关键元素。这些是组织写法，不是API参数或效果保证。

| 需要稳定什么 | 写法 |
|---|---|
| 人物身份 | 固定一组可见特征，每镜沿用同一角色名和同一外观短语 |
| 参考分工 | @图片1锁外观，@图片2只参考服装，明确排除项与优先级 |
| 轴线 | 海始终在画面右侧；人物向右行走 |
| 人数/物件数 | 全片一位主角、一台相机 |
| 摄影 | 本段固定机位/本段35mm中景，避免多个冲突运镜 |
| 反应与状态 | 听者先听完再回答、不跟读；钥匙/外套/泪水状态跨镜连续 |

## 3. 特殊参考：关键帧、宫格、白模、音频

### 3.1 关键帧 / 宫格 / 白模

- **关键帧**：多张独立图片，开头写「以@图片1至@图片N的顺序作为关键帧」。严格首尾帧优先用first_frame/last_frame角色，ratio必须adaptive。
- **近似首尾帧**：也可用reference_image并写「@图片1为首帧」「@图片3为首帧、@图片5为尾帧」。此方式不锁定输出画幅，画面与参考图相近但不完全匹配，可与其他多模态参考组合。
- **宫格/故事板**：建议少于15格，用简约线稿，少在格内写文字。主要提供剧情骨架，不能保证每格严格复现；要更强画面对齐用独立关键帧。避免脏污、过度锐化或与文字说明矛盾的AI宫格图。
- **粗粒度白模**：用简单几何体表达动作、构图、运镜，明确参考哪种动态信息，再指定目标材质、人物和光影。
- **精细白模**：完整、干净的白模视频也可用于重渲染。参考图主体与白模对象逐一对应，目标画面描述与白模动作/镜头一致；去除轨迹线、坐标轴和相机视锥，避免带入成片。

### 3.2 仅音频参考

标准版与flash均支持无图片/视频的reference_audio。明确参考的是音乐节拍、旋律、台词还是音色；生成音轨会重做，不等于原样贴参考。

```text
@音频1作为节拍与情绪参考。清晨城市从安静街巷切到通勤人群，
镜头运动与节奏逐渐加快。只保留环境声和音乐，不要旁白，不要字幕。
```

### 3.3 负向音频与字幕控制

可以写「不要字幕」「不额外加入对白字幕」「无bgm，只生成环境音和动作音」「不要对白」，但这些是概率性约束。完全无声用API `generate_audio=false`（CLI `--no-generate-audio`）。

- 不要字幕失效时，确保参考图和视频本身无字幕；避免在台词后复述词语再追加语气/动作，可改成「角色台词（情绪）：内容」。
- 无bgm失效时，可明确排除背景音乐、配乐、旋律、伴奏等相关形式，并在prompt开头和结尾各写一次音频政策；仍需检查成片。
- 后期人声隔离也会去掉动作音与环境音，不能当作无损保留音效的等价方案。

## 4. 镜头、光影、文字与声音

### 视觉描述

| 维度 | 可用表达 |
|---|---|
| 景别 | 全景交代空间，中景表现动作，特写突出表情/产品细节 |
| 运镜 | 固定机位、缓慢推进/拉远、横移、跟拍、环绕、升降 |
| 角度 | 平视、低机位仰拍、俯拍、主观视角 |
| 光影 | 柔和侧光、逆光轮廓、窗边散射光、霓虹反射；写清主要光源方向 |
| 风格 | 写实纪录片、电影、定格黏土、2D扁平、白模；选与任务一致的风格 |
| 物理 | 风吹衣摆、液体沿杯壁流下、脚步带起细沙；写因果与方向 |

动作写成可见变化，如「停步，右手轻扶帽檐，回头看向海面」，少用「高级感」「震撼」替代具体画面。复杂动作可用参考视频帮助控制，无需一律改成小动作。

### 台词、音色与字幕

对白使用引号，并明确说话人、语种、情绪、语速。例：`旅行者轻声说：“我们到了。”`。两款模型支持中文、英文、西班牙语、印度尼西亚语、葡萄牙语、日语、马来语、泰语、阿拉伯语、越南语、韩语；语种支持不代表每次口型或音色完全稳定。

```text
@图片1的主角使用@音频1的音色，语速舒缓，轻声说：“今天，我们从这里出发。”
另一角色先听完再回答，不跟读这句台词。环境音为轻微风声与海浪，无bgm，不额外加入对白字幕。
```

**官方系列教程推荐**音乐用 `()`、音效用 `<>`、台词用 `{}`、画面文字用 `【】` 区分；API也建议对白使用双引号。它们是提示词组织方式，不是独立控制通道；选择一种清晰一致的写法，不承诺符号自动保证口型、字幕或文字准确。

### 画面文字

写出**准确文本、位置、出现时段与样式**，缩短字数。英文拼写易错时可将单词拆成独立字母并要求按顺序出现；中文关键文案可制成正确文字参考图并绑定到对应画面。逐镜检查远景、近景和遮挡后的拼写与时序，关键排版与长文案优先后期完成。

### 常见问题

| 观察到的问题 | 调整 |
|---|---|
| 人物身份漂移 | 减少冲突参考、清晰绑定角色、沿用相同外观短语 |
| 人物重复/混淆 | 每个角色独立映射，按首次出场排序，明确总人数与站位 |
| 动作只执行一部分 | 减少同段事件，增加合理时间，优先重要动作 |
| 运镜含糊 | 每段一个主要运动，配合景别、起止方向 |
| 多出字幕/Logo | 检查参考图和视频中的文字，明确无需额外字幕/Logo |
| 声音不匹配 | 区分说话人/音色/音乐参考，缩短台词，检查音频质量 |
| 首帧画幅不合适 | 严格首帧模式先调整构图，再ratio=adaptive，不强行指定9:16 |
| 多项参考与编辑同时不稳定 | 拆成参考生成与编辑两步，再后期整合 |

## 5. 编辑与延长

### 编辑

两款都用reference_video + edit + ratio=adaptive + duration=-1，待编辑视频4–30秒。prompt写目标视频、修改范围、A→B、保留项。附带多张图时，明确各图作用；官方建议源片20秒以内、附图1–5张更稳，这不是硬上限。

```text
编辑@视频1：仅把4-6秒人物手中的蓝色杯子替换为@图片1的白色陶瓷杯。
其余时段、人物动作、背景、运镜和声音保持原样，不新增人物。
```

编辑输出与源片**基本对齐**，可能为非整数秒。官方指南列出的外部输入典型差异约0.33秒，API说明约0.4秒；指南说明2.5系列自产源无此差距。严格等长时可将输入帧数调为`8n+1`，或改走参考生成并指定duration（不再属于严格编辑）；最终以媒体元数据验证。

**需要改宽高比时改走参考生成，不用编辑**；补充具体剧情与逐镜时序对应。编辑锁源画幅，直接改比例可能引入额外内容与时长变化。

也可只改音频：`仅编辑@视频1的台词，改为“明天见”，语速与原片接近；画面不变。`。有声/无声需求同时匹配generate_audio设置。翻译配音要覆盖所有可辨识人声（包括背景对话、耳语、感叹词），逐角色提供完整目标语言台词和时间轴，并要求口型同步、其余内容保留。

编辑保持性需要看片验证，不保证所有未指定内容逐像素不变。

### 无缝转场

输入两段reference_video，prompt明确从@视频1结尾如何过渡到@视频2开头。可用auto + ratio=adaptive + duration=-1，检查输出衔接与总时长。

```text
将@视频1和@视频2衔接起来：承接@视频1末尾纸船向右漂行的动作，
水面反光自然过渡到@视频2开头的湖面，保持同一暖调与水声。
```

### 延长

两款都用reference_video + extend + ratio=adaptive，建议MOV进出。`duration`为**成片总时长**：源片5秒，再续7秒，传12。

```text
向后延长@视频1。紧接@视频1结尾纸船漂过石桥的动作，
镜头继续跟随，纸船进入阳光下的开阔水面，最后平稳停镜。
```

向前延长需写清如何接回原片开场。延长后的音量可能略变，2.5系列自产源通常更利于声画衔接，仍需听完整音轨。多轮续写可能累积身份/清晰度漂移；发现漂移后调整参考或重新生成所需片段。flash无Draft，普通预览task不能作为Draft升版输入。
