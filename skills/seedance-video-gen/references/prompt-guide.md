# Seedance 2.5 系列提示词指南

适用于标准版与flash，共用[官方提示词指南](https://console.volcengine.com/ark/region:cn-beijing/docs/seedance-2-5-prompt-guide)（2026-11-15）。选择flash改变容量和输出上限，不改变提示词语法。参数约束见 [seedance-2.5.md](seedance-2.5.md)，场景示例见 [scene-cookbook.md](scene-cookbook.md)。

## 1. 单镜头：直接描述可拍出的画面

按「主体＋动作＋场景＋镜头＋光影/风格＋声音」写。4–5秒单动作不需要强行拆镜或填写长模板。

```text
黄昏海岸，一只橘猫坐在木栈道上，缓慢转头看向海面。
低机位中景轻微推进，暖色逆光勾勒毛发。
只保留海浪与风声，无背景音乐，不要字幕。
```

首帧已给出主体外观，prompt重点写动作、机位、光线变化与声音，少复述图中细节。首尾帧写两幅画面间合理的动作过程；跨度过大时增加时长或调整素材。严格首帧/首尾帧用API角色，ratio必须adaptive。

**长度建议**：中文≤500字，英文≤1000词；过长会分散注意力。将最关键的主体、动作和约束放前面。可用自然中文，不要求英文标签或固定段落全部出现。

## 2. 多镜头：绑定素材，再安排事件

官方基本结构为：**素材指代 → 一句话概述 → 具体情节（时间轴或镜头顺序）→ 全片约束**。按复杂度选用，不把每条短片都写成拍摄手册。

### 2.1 素材绑定与结构化示例

素材按各自类型的上传顺序编号：图片1、图片2、视频1、音频1。`@图片1`等写法是文本指代，不是API ID；CLI按每个对应参数出现的顺序构建素材列表。

```text
图片1是主角的外观参考；图片2只参考服装；视频1只参考缓慢跟拍的运镜；
音频1只参考主角音色。全片仅此一位主角，不新增人物。

一位旅行者在黄昏海边停下，发现随身相机里的旧照片，写实电影风格。

0-4秒：全景，旅行者沿栈道缓慢走来，夕阳从画面右侧照入。硬切。
4-9秒：中近景，她停下低头查看相机，轻声说：“原来你一直都在。”
9-12秒：切相机屏幕特写，显示一张海边旧照片，镜头停稳。

保持同一服装、光源方向和场景轴线。只生成海浪、脚步与对白，无bgm，不要额外字幕。
```

需要明确职责时，可用以下标签组织，但它们不是模型专用控制词：

| 标签 | 写什么 |
|---|---|
| GLOBAL STYLE | 题材、视觉风格、色调、全片约束 |
| SCENE | 一句话事件 |
| CHARACTERS / LOCATION | 主体映射、空间关系 |
| FIRST FRAME AND BLOCKING | 开场位置、朝向、站位 |
| Shot N | 每镜景别、机位、动作、声音与衔接 |
| OPTICS / LIGHTING / PHYSICS | 有实际意义时再指定焦段、光源、材质运动 |
| AUDIO | 说话人、对白、环境音、音乐与音效 |

多角色逐一绑定外观与声音，不只在图片里写人名。参考已准确表达动作时写清「只参考视频1的动作/运镜，顺序一致」，少写可能冲突的逐帧复述。素材用量服从模型上限：标准版30/10/10，flash10/5/5。

### 2.2 时间轴与切镜

两款模型均支持以**整数秒**描述事件；可用连续区间、时间点或相对时间，也可以直接写镜头序号。

- 连续区间：`0-3秒…3-7秒…7-12秒…`，不跳过未解释的时间段。
- 时间点：`第5秒切到俯拍全景`。
- 相对时间：`按下快门后定格1秒`。
- 不用时间戳控制高频动作次数，如「每秒摇头3次」。

每段安排足够完成的动作与对白；内容过密会遗漏或过度剪切。时间戳帮助表达意图，不是逐帧剪辑保证。30秒可以分成少量事件段，最后留稳定收尾；无需固定节拍数量。

需要切镜时写「硬切 / Hard cut」并描述新镜头的景别和对象；长镜头明确「一镜到底」和连续机位运动。不把「缓慢升起」与同段「固定机位」放在一起。

### 2.3 稳定性约束（named locks）

用简明正向约束明确关键元素。这些是组织写法，不是API参数或效果保证。

| 需要稳定什么 | 写法 |
|---|---|
| 人物身份 | 固定一组可见特征，每镜沿用同一角色名和同一外观短语 |
| 参考分工 | 图片1锁外观，图片2只参考服装，明确冲突时的优先级 |
| 轴线 | 海始终在画面右侧；人物向右行走 |
| 人数/物件数 | 全片一位主角、一台相机 |
| 摄影 | 本段固定机位/本段35mm中景，避免多个冲突运镜 |
| 状态 | 雨水逐渐增多，已打开的包装保持打开 |

## 3. 特殊参考：关键帧、宫格、白模、音频

### 3.1 关键帧 / 宫格 / 白模

- **关键帧**：多张独立图片，开头写「以图片1至图片N的顺序作为关键帧」。用reference_image是参考任务，不自动锁定ratio/duration；要求严格首尾帧时使用first_frame/last_frame角色。
- **宫格/故事板**：建议少于15格，用简约线稿，少在格内写文字。主要提供剧情骨架，不能保证每格严格复现；要更强画面对齐用独立关键帧。
- **白模**：简单几何体表达动作、构图、运镜。明确参考哪种动态信息，再指定目标材质、人物和光影；去除轨迹线/坐标轴，避免带入成片。

### 3.2 仅音频参考

标准版与flash均支持无图片/视频的reference_audio。明确参考的是音乐节拍、旋律、台词还是音色；生成音轨会重做，不等于原样贴参考。

```text
音频1作为节拍与情绪参考。清晨城市从安静街巷切到通勤人群，
镜头运动与节奏逐渐加快。只保留环境声和音乐，不要旁白，不要字幕。
```

音色参考用清晰独立人声，配乐参考用单独音乐段；复杂混音会增加分离难度。纯正弦音没有足够语义信息，不宜用于驱动叙事。

### 3.3 负向音频与字幕控制

可以直接写「不要字幕」「不额外加入对白字幕」「无bgm，只生成环境音和动作音」「不要对白」。要完全无声时，用API `generate_audio=false`（CLI `--no-generate-audio`）。

## 4. 镜头、光影、文字与声音

### 视觉描述

| 维度 | 可用表达 |
|---|---|
| 景别 | 全景交代空间，中景表现动作，特写突出表情/产品细节 |
| 运镜 | 固定机位、缓慢推进/拉远、横移、跟拍、环绕、升降 |
| 角度 | 平视、低机位仰拍、俯拍、主观视角 |
| 光影 | 柔和侧光、逆光轮廓、窗边散射光、霓虹反射；写清主要光源方向 |
| 风格 | 写实纪录片、电影、定格黏土、2D扁平、白模；选与任务一致的风格 |
| 物理 | 风吹衣摆、液体沿杯壁流下、脚步带起细沙；写因果与方向 |

动作写成可见变化，如「停步，右手轻扶帽檐，回头看向海面」，少用「高级感」「震撼」等替代具体画面。复杂动作可用参考视频帮助控制，无需一律改成小动作。

### 台词、音色与字幕

官方API建议对白使用引号，并明确说话人、语种、情绪、语速。例：`旅行者轻声说：“我们到了。”`。两款模型支持中文、英文、西班牙语、印度尼西亚语、葡萄牙语、日语、马来语、泰语、阿拉伯语、越南语、韩语；语种支持不代表每次口型或音色完全稳定。

```text
图片1的主角使用音频1的音色，语速舒缓，轻声说：“今天，我们从这里出发。”
环境音为轻微风声与海浪，无bgm，不额外加入对白字幕。
```

要画面文字时写出**准确文本、位置、出现时段与样式**，缩短字数；成片检查拼写与时序。API没有专用字幕字段。

既有场景示例可能用 `（）` 标音乐、`<>` 标音效、`{}` 标对白、`【】` 标画面文字；这些只是便于阅读的**提示词组织习惯**，不是强制语法或独立控制通道。自然语言和引号同样可用，不承诺符号自动保证口型或文字准确。

### 常见问题

| 观察到的问题 | 调整 |
|---|---|
| 人物身份漂移 | 减少互相冲突的参考、清晰绑定角色、沿用相同外观短语 |
| 人物重复/混淆 | 每个角色独立映射，明确总人数与站位 |
| 动作只执行一部分 | 减少同段事件，增加合理时间，优先重要动作 |
| 运镜含糊 | 每段一个主要运动，配合景别、起止方向 |
| 多出字幕/Logo | 检查参考图中的文字，明确无需额外字幕/Logo |
| 声音不匹配 | 区分说话人/音色/音乐参考，缩短台词，检查音频质量 |
| 首帧画幅不合适 | 先调整首帧构图，再ratio=adaptive，不强行指定9:16 |

## 5. 编辑与延长

### 编辑

两款都用reference_video + edit + ratio=adaptive + duration=-1，待编辑视频4–30秒。prompt写目标视频、修改范围、A→B、保留项。附带多张图时，明确各图作用。

```text
编辑视频1：仅把4-6秒人物手中的蓝色杯子替换为图片1的白色陶瓷杯。
其余时段、人物动作、背景、运镜和声音保持原样，不新增人物。
```

也可只改音频：`仅编辑视频1的台词，改为“明天见”，语速与原片接近；画面不变。`。有声/无声需求同时匹配generate_audio设置。编辑保持性需要看片验证，不保证所有未指定内容逐像素不变。

### 无缝转场

输入两段reference_video，prompt明确从视频1结尾如何过渡到视频2开头。可用auto + ratio=adaptive + duration=-1，检查输出衔接与总时长。

```text
将视频1和视频2衔接起来：承接视频1末尾纸船向右漂行的动作，
水面反光自然过渡到视频2开头的湖面，保持同一暖调与水声。
```

### 延长

两款都用reference_video + extend + ratio=adaptive，建议MOV进出。`duration`为**成片总时长**：源片5秒，再续7秒，传12。

```text
向后延长视频1。紧接视频1结尾纸船漂过石桥的动作，
镜头继续跟随，纸船进入阳光下的开阔水面，最后平稳停镜。
```

向前延长需写清如何接回原片开场。多轮续写可能累积身份/清晰度漂移；发现漂移后调整参考或重新生成所需片段。flash无Draft，普通预览task不能作为Draft升版输入。
