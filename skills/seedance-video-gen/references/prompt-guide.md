# Seedance 提示词指南（默认 2.5）

纯写法。能力边界见 [key-constraints.md](key-constraints.md)；参数/token/任务锁定见 [seedance-2.5.md](seedance-2.5.md)。默认按 **2.5** 写；只有显式切 2.0（4k / fast 预览）才用附录 A。

## 0. 快速决策树

| 你要什么 | 写法 |
|---|---|
| 4–5s 单动作 | 一句话（§1） |
| 多切镜 / 8–30s / 跨镜锁脸 | §2 分段结构（`GLOBAL STYLE` + `Shot N` + `Hard cut.`） |
| 仅音频 / 关键帧 / 宫格 / 白模 | §3 |
| 显式切 2.0（4k / fast 预览） | 附录 A（镜头1/2/3，**不要写精确秒数**） |

## 1. 简单 shot 公式（2.5 / 2.0 共用）

按任务类型选模板。复杂叙事不要硬套一句话，改走 §2。

### 文生视频

```text
[主体描述] + [动作/运动] + [场景/环境] + [光影色调] + [运镜] + [视觉风格/画质] + [约束] + （BGM） + <音效> + {台词}
```

### 首帧图生视频

```text
@图片1 [画面里要发生的动作/运动] + [运镜方式] + [光影变化] + [音频描述] + [风格/画质] + [约束]
```

> 首帧图已锁定画面内容，不必再详写主体外观；重点写「怎么动」。`@图片1` 不是必需语法，但能锁定首帧引用。**2.5 必须 `--ratio adaptive`。**

### 首尾帧图生视频

```text
[从图片1到图片2的转场逻辑/动作过程] + [运镜] + [时长分配] + [风格/约束]
```

> 首尾帧要能合理过渡（同一场景、同一主体、合理时间差），主体跳跃过大容易 artefact。

### 多模态参考（图+视频+音频组合）

```text
[素材绑定声明] + [主体定义] + [分镜时序] + [运镜/动作] + [音频整合] + [画质/风格] + [约束]
素材绑定示例：参考图片1中角色A的面部、图片2中角色A的服装、视频1的运镜节奏、音频1作为BGM
```

编辑 / 延长句式见 §5。素材组合规则见 [multimodal-reference.md](multimodal-reference.md)。

### 进阶通用公式

```text
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

模型在内部拆成「空间层」（画面里有什么）和「时间层」（事情如何随时间变化）。好提示词是工程型指令，不是文案型形容。

### 定义主体

`将<图片/视频N>中的[2-3个清晰的静态特征]定义为<主体N>`

```
将图片1中穿红色连衣裙、戴草帽的女人定义为张红
```

多人：每个角色明确定义，后续全程用同一标签：

```
将图片1中穿蓝色卫衣、戴眼镜的男孩定义为小明
将图片2中扎马尾、穿校服的女孩定义为小红
```

人脸参考：

- 用**大头照（仅面部，无表情）+ 全身照**，不要三视图/多视图
- 写清：`主体1的面部特征参考图片1（大头照），妆造参考图片2（全身照）`
- **重要素材放提示词越靠前**（注意力前置）
- 多视角参考**只适用于人物**；物体/商品/建筑不要多视角拼接
- 参考图先去文字/水印（否则会误生成字幕/Logo）

### 动作描述

1. **肢体细化 + 程度量化**：`缓慢抬手、快速转头、用力蹬地、微微低头`
2. **优先低缓连续小动作**：优先 `缓慢行走、轻轻抬手`，规避 `狂奔、大跳、剧烈翻滚`
3. **补充动作过渡衔接**：`借着转身惯性顺势抬手、从停顿状态自然过渡到举手`
4. **情绪具象外化**（用身体细节替代抽象词）：

| 情绪 | 外化动作 |
|---|---|
| 悲伤 | 低头、肩膀颤抖、眼眶泛红、手指攥紧衣角 |
| 喜悦 | 嘴角上扬、眉眼舒展、脚步轻快、哼小曲 |
| 紧张/焦虑 | 频繁看手表、手指敲击桌面、呼吸急促、眼神闪躲 |
| 愤怒 | 双拳紧握、下颌紧绷、胸口起伏 |
| 释然 | 长舒一口气、肩膀放松、露出久违淡淡的微笑 |

## 2. 2.5 复杂分段结构

多切镜 / 8–30s / 跨镜锁脸用这段。一项不写会在对应维度翻车，不是「写得越长越好」。**2.0 不要套用时间戳**，改附录 A。

结构：素材指代 + 概述 + 分镜/时间轴 + 结尾约束。音频符号仍是 `（）` / `<>` / `{}` / `【】`。

### 2.1 GLOBAL STYLE / SCENE / CHARACTERS / FIRST FRAME AND BLOCKING

```
GLOBAL STYLE：电影感写实，暖金黄昏，16:9，无字幕无 Logo 无真人明星脸
SCENE：栈道上一个女人停下看镜头
CHARACTERS：穿米色风衣的女人 = 图片1 面部 + 图片2 服装
LOCATION：海边木栈道，太阳在画面右侧
FIRST FRAME AND BLOCKING：开场她在画面左侧 1/3 处，面向海
Shot 1: 0-4s 全景缓慢前推。Hard cut.
Shot 2: 4-12s 中景跟拍，她转身说{我们到了}
OPTICS：47° 正常焦段，无镜头漂移
LIGHTING：单光源黄昏，逆光轮廓
AUDIO：<海浪>，无 bgm，不要字幕
SCREEN DIRECTION：海永远在画面右侧
```

| 段 | 写什么 |
|---|---|
| `GLOBAL STYLE` | 类型、色调、片种、画幅、禁止出现什么 |
| `SCENE` | 一句话发生了什么 |
| `CHARACTERS` / `LOCATION` | 人或空间；有参考图就点名「图片 N 是谁」 |
| `FIRST FRAME AND BLOCKING` | 开场谁在哪、朝哪 |
| `OPTICS` / `LIGHTING` / `PHYSICS` | 焦段或机位、光从哪来、布料/烟/液体怎么动 |
| `AUDIO` | 环境音、音效、不要什么。默认「无 bgm、无额外字幕」，对白用 `{}` |

主体绑定句式见 §1。**角色表（吃满参考位，但不要堆满 50）**：全身正面去脸 + 全身背面 + 3/4 带脸特写（笑/中性）。脸只出现在清晰特写里，否则宽景糊脸会被当成身份。每个必须稳定的元素一份参考。

音色写成一句 conditioning（口音/语速/口型习惯），每次台词原样粘贴。人声和音乐不要放进同一段 `reference_audio`。对白继续用 `{}`。

### 2.2 Shot N + 连续时间戳 + Hard cut

切镜之间写 `Hard cut.`（或中文「硬切」）。2.5 比 2.0 更吃「每镜写清机位/景别」；含糊转场是多镜头崩掉的第一原因。

时间戳区间必须连续：`0-3s ... 3-7s ... 7-15s` 或 `[1s-4s]`。不要跳秒。不要用时间戳写频率（「一秒摇头 3 次」）。

**30s 节拍结构**（社区共识 + 官方示例）：一条 30s 用 **4–5 个节拍、每拍 5–10s**；时间块骨架 `0-5s 定场 / 5-12s 动作展开 / 12-17s 停顿反应 / 17-25s 主事件 / 25-30s 收束定格`；最后 **1.5–2s 稳定收尾**（hold / reveal），不要安排动作。**每拍一个主动词**——一拍塞 >3 个动作时模型通常只执行第一个；整段动作过密时 2.5 会把 30s **压缩成 20–25s** 来塞内容（实测过密 prompt 成片偏短）。

```
0-3s：全景，女孩坐在地毯上玩纸飞机
3-8s：她起身，右手一挥把飞机放飞，镜头跟上
8-12s：飞机越过窗台，切到窗外城市黄昏
```

也支持 `[1s-4s]`、`第 5s 向左横移转场`、`3 秒后周围的人纷纷摇头`。环境写成事件轨：每道浪/每阵风带秒数，间隔不要均匀。

**节奏**：文戏用视频延长一镜到底；武戏分段独立生成后剪辑拼接。30s 是上限不是目标；只有一个动作就 4–8s。成片场景（短剧/产品/竖屏/编辑/延长/30s）见 [scene-cookbook.md](scene-cookbook.md)，不要在 cookbook 里再抄一遍本节公式。

### 2.3 Named locks 表

正向约束，不要堆在文末否定清单。

| Lock | 解决什么 |
|---|---|
| `FIRST FRAME AND BLOCKING` | 开场站位；反打时左右不互换 |
| `SCREEN DIRECTION` | 轴线：海在画右、沙丘在画左 |
| `LENS LOCK` / `SINGLE-LENS LOCK` | 每段一个焦段，或全片一个焦段只靠走位变景别 |
| `COUNT LOCK` | 正好 N 人，不要分身/镜面多一个 |
| `STILLNESS LOCK` | 列出「谁都不做」的动作 |
| `VERBATIM ANCHOR` | 角色锚点短语（服装颜色+发型+标志物+朝向）**每个镜头原样复制**，禁止同义词替换（「锈红色大衣」不要中途写成「深橙夹克」）——同义词会触发形象重设计。跨镜锁脸这一条比堆形容词有效 |
| 参考图排名 | 多张参考图时显式声明优先级：「图片1 只锁面部身份，任何情况不被覆盖；图片2 锁服装，与图片1 冲突时以图片2 为准」。不排名时图片之间会互相打架 |
| 状态单调 | 湿只增不减；道具只消耗不复原 |
| 替代禁止 | 禁止时给具体替代物，不要只写「不要血」 |

**多人物防同脸**（社区实测高频翻车）：每个角色**必须有自己的参考图 + 绑定行**（「图片1-2 是人物A，对应音频1；图片3-4 是人物B」）；人物映射不要只写在参考图里（图上写名字会导致角色混乱）。参考主体数官方稳定性建议：音/视频主体 1–5 个最佳（6–10 个需抽卡），图片主体 1–8 张（9–12 张需抽卡），>5 主体用单视图拆成多张。

### 2.4 实测注意（Ark live 2026-09-03）

token / 墙钟 / 像素仍在 [seedance-2.5.md](seedance-2.5.md)，此处只记对写法有影响的结论：

- **Hard cut**：12s 三镜里，`0-4s` 硬切到旗帜特写确实换镜头；「航拍拉升」只变成略高机位。**写清景别（全景/中景/俯拍）比写运镜动词可靠。**
- **仅音频**：须有语义的 wav/mp3；模型会重做音轨；纯音几乎不驱动画面。写法 §3.2。
- **延长**：`--duration` = 成片总时长；prompt 必须写「紧接结尾的具体动作」。写法 §5。
- **编辑**：运镜未必锁死。写法 §5。

**不要死磕 prompt 的事**：唱歌 → 预录轨并标明「他们正在唱的这段」；长时间肢体接触/群戏 → 先拍手机运动参考；10–15 次迭代仍烂 → 拆场景，一次只改一个变量，看完整成片再判。

## 3. 2.5 专属素材写法

### 3.1 关键帧 / 宫格 / 白模

**关键帧**：prompt 第一句 `以图片1至图片N的顺序作为关键帧`。要严格对齐画面用多关键帧，不要用宫格。

**宫格分镜**：一张图 ≤15 格，只提供剧情骨架，不严格对齐画面。

**白模（两种用法）**：

1. **参考运镜/动作/光影**（2.5）：写明参考的是运镜、动作还是光影；粗粒度几何体更好。细粒度白模去掉轨迹线/坐标轴，否则会烧进成片。
2. **延长防劣化桥接**：多次延长后易模糊、风格漂移、人脸失真。先出 1–2s 中性灰模再续写，后期用正常画面替换白模段。

```
白模渲染，灰色泥塑质感，中性柔光，无材质纹理，仅保留几何形体和动势，固定机位三脚架拍摄，无背景细节，clay render grayscale maquette
```

风格词也可直接写 `clay render` / `grayscale maquette`（见 §4 风格词表）。

### 3.2 仅音频参考 prompt

仅 2.5 允许不配图、只丢音频。参考须是**有语义的 wav/mp3**（BGM / 旁白 / 清晰节拍）。纯正弦几乎不驱动画面。默认 `generate_audio=true` 会**重做音轨**，不是原样粘贴参考。

```
画面跟随音频1的节拍与情绪：黄昏海岸镜头缓慢前推，<海浪>，不要字幕。
```

人声和音乐不要放进同一段 `reference_audio`。CLI：`--reference-audio file.wav`，不要配图。

### 3.3 负向音频控制

2.5 吃负向指令；想关字幕/BGM 时写清楚，不要只靠文末约束词碰运气。

| 意图 | 写法 |
|---|---|
| 不要烧字幕 | `不要字幕` |
| 只要环境/动作音 | `无 bgm，只生成环境音和动作音` |
| 完全静音 | `不要任何声音`（或 CLI `--no-generate-audio`） |

## 4. 共用技巧（运镜 / 光影 / 风格 / 音频 / 约束）

2.5 与 2.0 共用。复杂 2.5 片把这些词填进 §2 各段，不要另起一套文案。

### 运镜词表

**一个镜头只指定 1 种运镜**，不要同时要求推拉摇移。2.5 多镜时**景别优先于运镜动词**（§2.4）。

**运镜稳定性**（社区实测，18183 运镜测试）：

- 推/拉最稳；**环绕 orbit 和快速摇镜偶尔扭背景**——把一个 360° 环绕拆成两次推近（正面→侧面、侧面→背面）更稳
- 单镜运镜幅度控制在**画面宽度的 ~30% 以内**，速度词写「缓慢/匀速」
- **固定机位 + 主体运动**是最稳的方案；口播/对话/产品特写默认 locked-off
- 运镜方向与主体运动方向保持一致
- 主体要穿过空间时优先跟拍，不要让镜头自己大幅移动

**防"滑行/月球漫步"物理词**（脚步贴地、有重量）：

```
鞋底与地面每步产生细碎碎石飞溅，脚步落地有重量感，
重心随迈步快速前倾，头发和衣摆跟随动作延迟 0.3 秒甩动
```

#### 运动

| 英文 | 中文 | 说明 |
|---|---|---|
| `push-in` / `dolly in` | 推进 | 主体向镜头靠近 |
| `pull-back` / `dolly out` | 拉远 | 镜头后退，展现环境 |
| `tracking shot` | 跟拍 | 镜头跟随主体移动 |
| `orbit` / `360° orbit` | 环绕 | 绕主体旋转，适合产品展示 |
| `handheld follow` | 手持跟拍 | 纪实感、微晃 |
| `locked-off` / `static` / `tripod shot` | 固定机位/锁镜头 | 不运动，适合口播/访谈 |
| `slow pan` | 慢速摇镜 | 镜头水平转动 |
| `tilt up/down` | 仰拍/俯拍摇镜 | 镜头上下转动 |
| `crane up/down` | 升/降镜头 | 摇臂升降 |
| `whip pan` | 快速甩镜 | 快速转场 |
| `drone shot` / `aerial view` | 无人机航拍 | 高空俯瞰，大场景 |
| `over-the-shoulder (OTS)` | 过肩镜头 | 从角色肩膀后方拍摄对话方 |
| `zoom-in fade` | 变焦渐隐 | 焦距推进 + 画面淡入/淡出 |
| `Dutch angle` | 荷兰角/倾斜构图 | 不安、紧张感 |
| `POV` / `first-person view` | 第一视角 | 模拟角色视角 |

#### 角度

`eye-level`、`low-angle`（仰拍）、`high-angle`（俯拍）、`overhead`/`top-down`（上帝视角）、`worm's-eye view`（虫视）、`Dutch angle`

#### 景别

`extreme wide`/`establishing shot`（大远景/定场）→ `wide`（全景）→ `medium shot`（中景）→ `medium close-up`（中近景）→ `close-up`（特写）→ `extreme close-up`（大特写）

### 文字生成技巧

可以生成画面内文字（广告语、字幕、对话气泡），但文字准确性是统计性的，复杂长句容易出错：

| 文字类型 | 写法建议 |
|---|---|
| 广告语/品牌字 | 尽量短（2-6 字），配合大特写镜头，如：`画面中央用粗黑体大字显示"SALE 50%"` |
| 字幕/唱词 | `【】`标记；**优先横屏 16:9 生成**（竖屏字幕容易出现位置漂移和裁切）|
| 对话气泡 | 在描述中指定位置和形态，如：`角色头顶出现一个白色对话气泡，里面写着"你好"` |
| 招牌/场景文字 | 描述招牌位置+内容，近景镜头更容易识别 |

> **防字幕漂移**：横屏 16:9 比竖屏 9:16 字幕稳定性更高。参考图/视频素材务必先去除自带文字。**不要同时要求「无字幕」和「字幕」**——二选一。2.5 关字幕优先用负向控制（§3.3）。

### 音频提示词技巧

原生音视频联合生成。符号两代相同。

| 音频类型 | 写法 | 示例 |
|---|---|---|
| 背景音乐 | 用 `（）` 包裹 | `（背景中播放着快节奏的摇滚乐）` |
| 场景音效/Foley | 用 `<>` 包裹 | `<远处传来狗叫声>`<br>`<清脆的苹果碰撞声>`<br>`<冰块碰撞声与摇晃声卡点轻快鼓点>` |
| 角色台词/对白 | 用 `{}` 包裹 | `{你好，世界}` |
| 小语种台词 | `{}` + 语种标注 | `用日语说道{こんにちは}`<br>`用韩语回答{감사합니다}` |
| 京剧/国风唱腔 | `{}` + 唱腔描述 | `用京剧梅派青衣唱腔吟唱{海岛冰轮初转腾}` |
| 旁白/Narration | 直接在分镜中描述 | `一个深沉平静的男声说："在宏大的宇宙中..."` |

音视联合：

1. **音效与动作同步**：动作和音效写在一起，模型会自然对齐
   ```
   你的手摘下一颗带晨露的苹果，<清脆的苹果碰撞声>
   ```
2. **背景音乐用 `（）` 指定情绪/风格/节奏**
   ```
   0-5s：（背景中播放着悠远的古琴乐）黄昏，悬崖边的古松旁，白衣剑客缓缓收剑入鞘
   ```
3. **台词和口型自动对齐**：`{}` 中的台词自动匹配口型；2.5 支持 11 种语言、2.0 支持 6 种（清单见 [key-constraints.md](key-constraints.md)）
4. **单声道 mono**：输出为单声道（与输入声道数无关），环境声和台词分层混合
5. **中文发音不准**：把易读错的字换成同音常用字（`螭龙山` → `吃龙山`）
6. **音色漂移**：补充细致的音色特征
   ```
   使用音频1低厚温润带细碎颗粒感中年男声的音色说：
   ```
7. **视频结尾噪音**：含旁白的片尾突兀咔哒/杂音是已知问题，后期做音频淡出
8. **台词密度**（社区实测）：按 **2.5–3 个词/秒**写（中文每秒约 4–6 字），8s 片段台词 ≤ ~20 个英文词；塞太满会像念免责声明。语气提示**只用一个副词**（「平静地」「压低声音，几乎自言自语」），不要堆三个
9. **旁白/画外音不要口型**：角色不该说话时显式写 `禁止画面中角色出现说话口型，旁白为画外音`
10. **音效要挂在可见动作上**：「盒盖合上时一声轻响」会对上；游离音效（无来源的 `<远处狗叫>`）容易被丢或错位
11. **环境音点名空间**：「午间拥挤的咖啡馆背景声」是视觉已过时最便宜的提示词升级
12. **每个 prompt 结尾都写一句声音**：不写时模型会自作主张——广告感画面默认加 BGM。`无 bgm` / `no music` 是 2.5 执行率最高的负向指令之一
13. **多语言切换按时间窗隔开**：一个时间窗内只说一种语言，切换语言时用新镜头/新时间段并标注「用日语说道」；2.5 支持中/英/西/印尼/葡/日/马来/泰/阿拉伯/越/韩共 11 种
14. **官方字数建议**：中文 prompt ≤ 500 字、英文 ≤ 1000 词（过长信息分散会丢细节；脚本超限仅告警）；30s 复杂分镜实际建议 200–400 字主干 + 镜头块

2.5 有声分镜示例（时间戳）：

```
0-4s：（背景音乐描述）[环境音效] [运镜] [主体动作] [角色]说{台词}
4-10s：<场景音效> [运镜] [主体动作] ...
全程[画质/风格/约束]，环境音效与音频1自然融合
```

2.0 用「镜头1/2/3」的等价写法见附录 A。

### 约束词模板

放在提示词末尾，按场景组合。复杂 2.5 片：能写成 named lock 的不要只堆在这里（§2.3）。

**基础约束（几乎必加）**：
```
无字幕，无Logo，无水印，无闪烁，画面流畅不卡顿，人物面部稳定不变形，五官比例自然，无穿模，肢体动作自然不僵硬，身体比例稳定
```

**多人物场景追加**：
```
视频全程禁止出现外形着装配饰完全一致的人物，禁止生成同款分身或双胞胎效果，每个角色保持独立身份特征
```

**商品/产品视频追加**：
```
产品外观保持不变形，Logo清晰可辨，材质质感一致，无穿模
```

**竖屏短视频追加**：
```
竖屏构图，主体居中，安全区域内构图（避开底部字幕区）
```

> ⚠️ **约束词是软引导，不是硬开关**。「无字幕」「无双胞胎」能显著降低概率但不能 100% 消除；出问题优先修参考素材（去文字、不用三视图）和主体定义，而不是单纯堆约束词。

### 特殊符号

| 类型 | 符号 | 示例 |
|---|---|---|
| 音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 台词 | `{}` | `{你好，世界}` |
| 小语种/戏曲台词 | `{}` + 标注 | `用日语说道{こんにちは}` / `用京剧唱腔{...}` |
| 字幕 | `【】` | `【第一章：启程】` |

### 语言与素材引用规则

- 运镜/光影/风格推荐英文，台词可用中文
- 台词语言统一，避免中英混用（专有名词除外）
- 素材引用必须用 `图片n`/`视频n`/`音频n`（n 为**同类型素材**在 content 数组中排序，从 1 开始），不支持 Asset ID 直接指代
- 可选在主体引用前加 `@图片N` / `@视频N` 强化绑定
- 提示词不能直接用完整剧本原文，需精简无关表述
- **提示词没有硬性字数上限**，建议核心控制在 300 字以内，分镜可按需拉长

### 常见翻车与 Prompt 层解法

| 现象 | Prompt 层解法 |
|---|---|
| 人物撞脸明星/中途换脸 | 大头照前置 + 面部特征详细描述 + 不用三视图 |
| 视频自动带字幕 | 加 `无字幕` / 2.5 写 `不要字幕`、优先横屏、参考素材去文字 |
| 2D/3D 风格漂移成真人 | 提示词前置 `2D日漫风格` / `3D国风漫画` / `clay render`，参考图先转风格 |
| 画面出现双胞胎 | 明确角色-参考图绑定、末尾加「禁止同款分身」、不用三视图 |
| 特效不符合预期 | 用参考视频定义特效，不靠文字描述复杂特效 |
| 参考人物超过 4 人 | 分组生成（每组 ≤ 4 人），再后期合成 |
| 视频结尾有噪音 | 剪映音量包络线末尾下拉至 0，做音频淡出 |
| 中文多音字发音不准 | 替换为同音常用字 |
| 音色与参考音频不匹配 | 补充音色特征描述（年龄/性别/厚度/颗粒感/情绪）|
| 首帧图生视频画面跳变 | **2.5 必须 adaptive**。2.0 建议 adaptive 或预裁图 |
| 2.5 想关字幕/BGM | 负向控制：`不要字幕` / `无 bgm，只生成环境音和动作音` |
| 延长衔接处跳变 | 前段删 6 帧 + 后段删 1 帧，转场切镜结尾；或用白模桥接 |
| 延长后画质劣化 | 白模转场法（§3.1），优先高清参考，避免超过 2 次续写 |
| 2.5 多镜切不干净 | 每镜写清景别 + `Hard cut.`（§2.2 / §2.4），不要只写运镜动词 |
| 2.5 延长整段换景 | prompt 写「紧接@视频1结尾：具体动作」，不要只写「延续同一场景」 |
| 30s 成片被压缩到 20–25s / 后段动作丢失 | 每拍一个主动词，4–5 拍封顶；砍掉次要动作或拆 extend 链 |
| 环绕/摇镜背景扭变 | 拆成两次推近；运镜幅度 ≤ 画面宽度 30%；固定机位+主体动 |
| 人物脚步滑行、无重量 | 物理接触词：脚步碎石飞溅、重心前倾、衣发延迟 0.3s（§4） |
| 比喻被字面化（「淡淡的红晕」→脸上一块红） | 写可见物理状态，不写文学比喻 |
| 画面内文字错别字 | 品牌字/字幕尽量后期加；必须生成时 2–6 字 + 大特写；错了用局部编辑重拍那几秒 |
| 多人群戏所有人长一张脸 | 每人一份参考 + 逐人绑定行；减人数；「禁止同款分身」 |
| 2.5 提示词被审核拒（2.0 能过的） | 2.5 审核更严（社区反馈）：弱化暴力/恐怖措辞，或退回 2.0 出该镜头 |
| 延长链第 4–5 轮起脸糊/色偏 | 续写链控制在 2–3 轮（约 2–3 分钟成片）以内；超了重新生成种子段再续 |

## 5. 编辑 / 延长 prompt

素材组合、CLI、任务类型锁定 → [multimodal-reference.md](multimodal-reference.md)。这里只写 prompt 句式。

⚠️ **指代陷阱**：编辑/延长要用 `@视频N` 或 `<视频N>`，**不要写成 `参考<视频N>`**——出现「参考」时，模型很可能切到多模态参考模式（基于该视频重新生成），而不是在原片上编辑/延长。

### 编辑

```text
@视频1 [具体编辑操作] + [保持不变的元素] + [新增/修改元素的细节] + [约束]
```

三步，第三步最常被漏掉：

1. `@视频1` 指源片（**不要**写「参考视频1」，那会走参考生视频重生成）
2. 写清 **A→B**：把什么改成什么；替换成具体物体时用 `@图片N` 给替换素材（「钻石」这种抽象词实测可能被画成珠子——语义精度是编辑的弱项）
3. 收尾锁死：**「其余画面/运镜/人物保持不变，不要新增人物，不要字幕」**

**局部/片段编辑**（live 已通，2026-09-04）：可以用时间戳圈定编辑范围，只改坏的那几秒，不用整片重抽——

```
@视频1 把 0-2s 的画面从晴天午后改为雨天傍晚，保留橘猫主体与动作，其余内容保持不变。不要字幕。
```

这就是「片段重拍」：30s 广告里第 7 秒坏了就只重生成那一段。2.5 自产片回灌编辑时时长 **0 误差**（实测 4.04s→4.04s；非 2.5 来源 ±0.3~0.4s）。编辑后局部画质可能略降，复杂大改用重生成 + 参考更稳。

2.5：`--ratio adaptive --duration -1`。live：**运镜未必锁死**；「保持运镜不变」不一定兑现，删路人可能长出新主角——prompt 写死「不要新增人物」。

### 无缝转场（两段成片补间隙）

两段已完成的视频之间补过渡，用参考模式（不是 edit/extend）：

```
将@视频1和@视频2衔接起来，中间用[具体过渡动作/元素变形]自然过渡，
保持两段的画面风格、光影与角色一致。不要字幕。
```

`--ratio adaptive --duration -1`（auto 任务类型即可）；live：两段 4s 片 → 8.06s 成片（总时长≈输入之和）。写法细节与 CLI 见 cookbook §16。

### 延长

```text
@视频1 [向前/向后]延长，紧接视频结尾/开头的动作/台词，[新发生的事件]，保持与前片风格/光影/角色一致
```

`--duration` 传**成片总时长**（源 5s 再续 7s → 12），不要把「再延长 N 秒」填进 duration。只写「延续同一场景」不够，必须写紧接的具体动作。衔接跳变 / 画质劣化见 §4 翻车表与 §3.1 白模。

## 附录 A. 2.0 镜头序号写法

**仅在显式切 2.0 时用**（4k、fast/mini 预览）。2.0 **不要写精确秒数**：对「0-3 秒做 X」执行率低。用「镜头1/2/3」或「先...然后...」。

```
镜头1：[运镜/切换方式] [主体动作与表情] [位置/空间变化] [音频]
镜头2：[运镜/切换方式] [主体动作与表情] [位置/空间变化] [音频]
镜头3：...
```

有声结构：

```
镜头1：（背景音乐描述）[环境音效] [运镜] [主体动作] [角色]说{台词}
镜头2：<场景音效> [运镜] [主体动作] ...
全程[画质/风格/约束]，环境音效与音频1自然融合
```

简单 shot 公式、词表、约束、翻车解法与 2.5 共用（§1 / §4）。2.0 最长 15s；复杂叙事拆 task 或后期拼接。场景主示例是 2.5 时间戳，2.0 改写见 [scene-cookbook.md](scene-cookbook.md) 各节「2.0 / fast / 4k」；单镜 4–5s 可直接套 cookbook §1/§4/§5 的共用条与 §6–8、§12。
