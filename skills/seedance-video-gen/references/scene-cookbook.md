# Seedance 场景 Cookbook

默认按 **Seedance 2.5** 写。分段骨架、时间戳规则、`Hard cut.`、named locks 只在 [prompt-guide.md](prompt-guide.md) **§2** 写一份，这里不重复公式。能力边界见 `key-constraints.md`。

**2.5 主示例**（整数秒时间戳；多镜加 `Hard cut.`，必要时短 `GLOBAL STYLE` / named lock）：§1 知识口播、§2–3 短剧、§4 产品、§5 竖屏/社媒、§9 对话气泡与旁白、§10 编辑、§11 延长、§13 变形、§15 的 30s 叙事、§16 无缝转场。每个 2.5 多镜示例都标了建议 `duration` / `ratio` / 是否必须 `adaptive`。

**两代共用**：简单 4–5s 单镜不必硬拆时间戳（§1 教育动画、§4 单镜产品、§5 单镜竖屏、§6–8、§12、§14 连续环绕）。

**2.0 / fast / 4k**：不要写精确秒数。把 `Shot N` / `0-xs` 改成「镜头1/2/3」或「先…然后…」（各节有一句改写；公式见 prompt-guide **附录 A**）。2.0 最长 15s，不要套 §15 的 30s 写法。

## 1. 教育动画 / 知识口播

**要点**：主体清晰、动作缓慢、信息密度适中、风格一致。

### 知识口播（2.5 主示例）

**2.5 参数**：`--duration 12 --ratio 16:9`，文生不必 `adaptive`。

```
GLOBAL STYLE：2D 扁平教育动画，浅色背景，16:9，不要字幕，不要 Logo
SCENE：讲师讲解水分子结构，切到模型再切回
CHARACTERS：穿白衬衫的年轻讲师，全程同一人
COUNT LOCK：画面里正好 1 人
LENS LOCK：口播镜固定机位，模型镜缓慢旋转

Shot 1: 0-4s 中景，讲师面向镜头说{水分子由两个氢原子和一个氧原子组成}。Hard cut.
Shot 2: 4-8s 特写，水分子模型缓慢旋转，氢、氧以不同颜色标出。<轻点提示音>
Shot 3: 8-12s 切回讲师中近景，她抬手示意说{记住，结构决定性质}，镜头轻微推近。

AUDIO：无 bgm，只要口播与轻提示音，不要字幕
```

**2.0 / fast / 4k**：去掉秒数与 `Hard cut.`，改成镜头1 讲师口播 → 镜头2 分子模型特写旋转 → 镜头3 切回讲师收束。`--duration` ≤15。

### 教育动画（4–5s 单镜，两代共用）

```
A 2D flat vector animation of a water molecule in a clean illustration style.
The molecule gently splits into two hydrogen atoms and one oxygen atom, a small
spark connects them briefly before they separate. Clean light blue gradient
background, soft diffused lighting, locked-off eye-level medium shot, slow and
clear motion. 无字幕，无Logo，无水印，无复杂背景细节。Pastel blue and white
palette, educational and friendly mood.
```

```
A 3D Pixar-style animation of a cartoon rocket on a launch pad. Countdown
numbers appear one by one【3...2...1...】then the rocket gently lifts off with
a small puff of smoke, ascending slowly toward the top of frame. Clean dark
blue gradient sky background with scattered stars, soft diffused lighting,
locked-off medium shot, 5-second clip. 无字幕，无Logo，无水印。Warm and
encouraging mood.
```

## 2. 短剧（文戏 / 对话）

**角色锚定优先**。每个角色必须明确定义，全程使用同一标签。对话台词用 `{}` 包裹。

**2.5 参数**：`--duration 12 --ratio 16:9`，文生不必 `adaptive`。有参考图/视频时仍按素材绑定，不必为了参考而改 `adaptive`（`adaptive` 只锁首帧/编辑/延长）。

```
将图片1中穿米色毛衣、长直发的女孩定义为主角，图片2作为宿舍场景风格参考，
参考视频1的运镜方式。

GLOBAL STYLE：高清电影纪实风，色调温暖，光影柔和，16:9，不要字幕，不要 Logo
SCENE：主角回宿舍，先装考砸再揭晓是玩笑
CHARACTERS：主角 = 图片1；两名舍友，各自身份稳定
COUNT LOCK：宿舍内正好 3 人（主角+两舍友），禁止同款分身
FIRST FRAME AND BLOCKING：开场主角在走廊左侧，面向宿舍门
SCREEN DIRECTION：宿舍门始终在画面右侧

Shot 1: 0-4s 傍晚走廊中景平稳跟拍，暖黄日光从窗外洒进，主角脚步轻快走到门口，停顿深呼吸，表情略紧张。<走廊脚步>
Hard cut.
Shot 2: 4-8s 室内中景，舍友一边整理书本一边抬头，其中一人笑着问{考得怎么样呀，过了吗}，半身特写在几人之间缓慢切换。
Hard cut.
Shot 3: 8-12s 主角近景先低头落寞，再抬头憋不住笑说{骗你们的}，舍友追着打闹，镜头缓慢拉远成宿舍全景。

AUDIO：无额外 bgm，只要环境与对白，不要字幕
人物面部稳定不变形，动作自然流畅，无卡顿无闪烁。
```

**2.0 / fast / 4k**：改写成镜头1 走廊跟拍到门口深呼吸 → 镜头2 室内舍友问{考得怎么样呀，过了吗} → 镜头3 揭晓{骗你们的}并拉远。不要写 `0-4s`。`--duration` 12–15。

```
SCENE：悬崖古松前，白衣与黑衣剑客对峙

COUNT LOCK：正好 2 人
SCREEN DIRECTION：古松在画左，悬崖云海在画右
FIRST FRAME AND BLOCKING：开场白衣剑客在古松前收剑，面向右侧云海

Shot 1: 0-4s 低角度全景，白衣剑客缓缓收剑入鞘，衣袂被山风吹起，镜头缓慢升起，远处云海翻涌。（悠远古琴）

Shot 2: 4-8s 中景固定机位，黑衣剑客从松树后走出，两人对视，风卷松针从两人之间飘过。黑衣剑客说{你终究还是来了}

Shot 3: 8-12s 特写推近白衣剑客，他微微低头、嘴角苦笑，说{有些事，总要有个了断}

人物面部稳定不变形。
```

**2.0 / fast / 4k**：镜头1 低角度收剑云海 → 镜头2 中景对视与台词 → 镜头3 特写苦笑收束。不要写秒数。

## 4. 产品广告

### 多镜产品（2.5 主示例）

**2.5 参数**：`--duration 12 --ratio 1:1`（或 `16:9`），文生不必 `adaptive`。若用首帧图，则 **必须** `--ratio adaptive`。

```
GLOBAL STYLE：Premium commercial，干净深色棚拍，无文字无 Logo 无人脸
SCENE：白色无线耳机充电盒开盖、转面、合盖
STILLNESS LOCK：桌面除产品外无其他物体；产品外观不变形
LENS LOCK：每镜一个焦段，不要同时推拉摇移

Shot 1: 0-4s 中近景，黑色反光大理石上充电盒缓慢开盖，柔和轮廓光勾边。Hard cut.
Shot 2: 4-8s 特写，镜头以产品为中心缓慢旋转，依次展示正面、侧面、背面与 USB-C。Hard cut.
Shot 3: 8-12s 中景，盒盖轻轻合上，镜头轻微拉远，产品居中定格。

不要字幕，不要 Logo，无人脸。材质金属感一致，无反射穿帮。
```

**2.0 / fast / 4k**：镜头1 开盖 → 镜头2 旋转展示三面 → 镜头3 合盖拉远。单镜 4–5s 预览可只用下面共用示例。

### 单镜产品（4–5s，两代共用）

```
A cinematic product shot of a minimalist wireless earbuds case on a reflective
black marble surface. The case slowly rotates open, revealing the earbuds inside.
Soft rim light highlights the matte white texture. Camera performs a slow
180-degree orbit, medium close-up. Premium commercial look, clean dark background.
无文字，无Logo，无人脸。
```

```
参考图片1、图片2、图片3中的相机，把背景换成白色，相机在一个白色桌子上，
镜头以特写的形式聚焦相机，然后以相机为主体缓慢旋转，清晰展示相机的正面
```

## 6. 首帧图生视频

4–5s 单动作，两代共用写法。**2.5 必须** `--ratio adaptive`（画幅锁首帧）；`--duration 5`。2.0 建议同样用 `adaptive`。

```
以提供的首帧图作为起始画面：卡通火箭缓慢点火，白色烟雾从底部喷出，火箭
开始微微震动然后离开地面向上升起，从画面底部逐渐向中间移动。
保持相同的扁平 2D 插画风格和粉彩色调。镜头固定机位，5 秒，平滑过渡，无突变。
```

## 7. 首尾帧图生视频

两代共用。**2.5 必须** `--ratio adaptive`；`--duration 5`。首尾帧要是同一主体、可合理过渡。

```
从首帧平滑过渡到尾帧。首帧是一本合上的旧书，尾帧是同一本书翻开、书页轻轻翻动。
镜头缓慢环绕书本 180 度，书页在移动中自然翻开。温暖的午后阳光从窗口照入，
保持一致的复古胶片风格和暖色调。5 秒，无突然跳变。
```

```
使用图片1作为角色风格参考，视频1作为运镜参考，音频1作为背景音乐。
```

## 9. 文字生成场景

### 广告语（4–5s 单镜，两代共用）

```
手绘漫画风格，三个人围坐在一起吃图片1中的炸鸡，气氛友好愉悦，
后画面逐渐模糊，画面中部显示文字"快乐尽在 Seedance"。
```

### 旁白 + 字幕（2.5）

**2.5 参数**：`--duration 12 --ratio 16:9`，文生不必 `adaptive`。时间连续、同一运镜，**不要** Hard cut。

```
GLOBAL STYLE：电影感风景，夜到黎明，16:9
AUDIO：深沉平静男声旁白；画面底部按台词出字幕

0-4s：夜晚群星，镜头缓慢前推，男声说{在宏大的宇宙中，我们的世界不过是一个短暂的瞬间}
4-8s：天色转蓝，星星逐渐消失，继续{然而，在其中，生命不顾一切地繁荣}
8-12s：太阳从山后升起，定场全景。不要 Logo。
```

**2.0 / fast / 4k**：改成「先夜景旁白，然后过渡到黎明，最后日出」；底部按台词出字幕。不要写秒数。`--duration` 12–15。

### 对话气泡（2.5）

**2.5 参数**：`--duration 12 --ratio 16:9`，文生不必 `adaptive`。

```
GLOBAL STYLE：校园日光写实，16:9，情绪明亮
CHARACTERS：图片1中的两人，运动服，身份稳定
COUNT LOCK：正好 2 人

Shot 1: 0-4s 操场中景，两人跑步，女孩看向男孩，自信地笑着说{We can definitely do it!}，说话者旁出现对应气泡。Hard cut.
Shot 2: 4-8s 男孩近景，他犹豫地回答{Are you sure?}，气泡跟说话者。Hard cut.
Shot 3: 8-12s 女孩中近景，语气轻快说{Yes!}，气泡跟说话者。

台词语言统一（本条全英文对白）。不要额外烧字幕条。
```

**2.0 / fast / 4k**：镜头1 女孩{We can definitely do it!} → 镜头2 男孩近景{Are you sure?} → 镜头3 女孩{Yes!}，气泡跟说话者。

## 10. 视频编辑（增删改 / 跨模态）

编辑句式见 prompt-guide **§5**。指代用 `@视频1`，**不要**写成「参考视频1」（否则容易变成按参考重新生成）。

**2.5 参数（整节）**：`--ratio adaptive --duration -1 --omni-reference-task-type edit`。**必须** `adaptive`；时长跟源片，不要自己填秒数。建议 `--output-format mov`。运镜未必锁死；删路人时写死「不要新增人物」。

### 增加 / 删除 / 替换（操作短，两代句式相同）

```
@视频1 在台面上添加炸鸡、披萨等小吃。保持人物、运镜、时长不变。不要新增人物。不要字幕。
```

```
@视频1 清除桌面上的其他零件和工具，保持桌面整洁干净，桌面上只有他俩手里的工具。
不要新增人物，不要字幕。
```

```
@视频1 将礼盒中的香水替换成图片1中的面霜，运镜尽量不变。产品不变形，不要字幕。
```

**2.0 / fast / 4k**：同样用 `@视频1` + 具体增删改；2.0 无 `omni-reference-task-type`。编辑仍建议 `adaptive` + `duration -1`。

### 跨模态：天气 / 光线 / 风格（2.5 主示例）

源片若明显分段，用连续整数秒对齐原片节奏（区间不要跳秒）。单气氛替换也可整段一句话，不必硬切。

**2.5 参数**：同上，`--ratio adaptive --duration -1`，必须 adaptive。

```
@视频1
GLOBAL STYLE：只换环境，不换角色与构图，不要新增人物，不要字幕
STILLNESS LOCK：原片里没有的人物不要出现

0-4s：晴午改为雨夜，天空深蓝黑，霓虹映在湿路面，雨丝细密，路灯暖黄光晕。
4s 后至结尾：维持雨夜，行人撑各色雨伞。
保持角色与节奏；运镜尽量不变（2.5 不保证锁死运镜）。冷青赛博朋克氛围。
```

```
@视频1 将白天商场改为黄昏黄金时刻：暖色夕阳光从玻璃天窗斜射，地面长影，店内灯缓缓亮起，光柱里有轻微浮尘。
保持人物动作、构图；不要新增人物，不要字幕。
```

```
@视频1 将实拍转为 2D 日漫：赛璐璐上色，清晰黑轮廓，高饱和，人物改为日漫大眼，背景保留构图但笔触简化。
保持所有动作与时长。不要字幕。
```

**2.0 / fast / 4k**：去掉秒数，写成「将晴午整段改为雨夜：…保持角色运镜节奏」。

## 11. 视频延长（含 BGM / 轨道补齐）

延长句式见 prompt-guide **§5**。`--duration` 是**成片总时长**（源 5s 再续 7s → `12`），不是「再延长 N 秒」。prompt 必须写「紧接结尾/开头的具体动作」，不要只写「延续同一场景」。

**2.5 参数**：`--ratio adaptive --omni-reference-task-type extend`。**必须** `adaptive`。下面示例按「源约 5s、成片 12s」来写时间戳，按你的源片改数字。

### 向后延长 + BGM（2.5 主示例）

```
向后延长@视频1。紧接视频1结尾（约第 5s）：
GLOBAL STYLE：与前片同一色调、光影、人物造型，不要字幕，不要 Logo
CHARACTERS：主角身份不变，不要新增路人成主角

5-8s：主角说完最后一句后停顿约一秒，缓缓转身走向窗边，中景跟随。
8-12s：窗外傍晚城市天际线，镜头从主角中景拉远到窗外大全景。
（背景音乐从音频1的钢琴曲渐入，情绪从略重转为释然）<远处城市车流声>

这是一镜跟出，不要 Hard cut 换场景。
```

**2.0 / fast / 4k**：写成「向后延长@视频1，紧接结尾：停顿、转身走向窗边，再拉远到窗外城市全景」；不要写 `5-8s`。2.0 成片仍 ≤15s。`--ratio adaptive`。

### 向前延长（2.5）

**2.5 参数**：`--ratio adaptive --duration 10`（新开场 5s + 源 5s 的示例），必须 adaptive。

```
向前延长@视频1。作为视频1的开场，紧接到原片开头：
0-5s：雨天咖啡馆外景全景定场，暖黄灯光从窗户透出，雨丝在街灯下可见，镜头缓慢推向门口。
（音频1轻柔爵士渐起）<雨声><风铃轻响>
然后接到视频1原开头，保持同一暖色复古胶片质感。不要字幕。
```

**2.0 / fast / 4k**：改成「先雨天咖啡馆外景推向门口，再接到视频1开头」。不要写秒数。

### 向后延长（短句） / 轨道补齐

```
向后延长@视频1。紧接视频1结尾：迟到的两个男士跑向他们，五个人终于见面，友好聊天。
保持前片人物与色调，不要字幕。
```

```
向前延长@视频1，给白衣男子过肩镜头，白衣男子说：{It's not that bad. You're
just stressed. Everyone goes through this, you just need to keep going.}
紧接到视频1原开头。
```

```
@视频1 树叶落地的瞬间，激起金色粒子特效，一阵风吹过，接@视频2。
保持两段色调衔接，不要字幕。
```

## 16. 视频无缝转场（两段成片补间隙，2.5）

**要点**：两段已经生成的视频之间让模型补过渡，属于全模态**参考**任务（不是 edit/extend）；用过渡动作/元素变形把两段缝起来。live 实测（2026-09-04）：两段 4s 成片 → 8.06s 输出，总时长≈输入之和。

**2.5 参数**：`--ratio adaptive --duration -1`；不传 `--omni-reference-task-type`（auto 即可）。视频 1、2 按 `--reference-video` 顺序传入。

```
将@视频1和@视频2衔接起来。视频1结尾的猫在午后阳光里眨眼，
中间用猫咪缓慢转头、阳光在毛发上流动的动作自然过渡到视频2开头的画面，
保持两段同一阳光午后的色调、光影与暖调风格。不要字幕。
```

```
@视频1 树叶落地激起金色粒子的瞬间，粒子被风卷成漩涡，
漩涡散开后接@视频2的室内场景，人物位置与运镜方向自然延续。
保持两段色调衔接，粒子转场约占 1 秒。不要字幕。
```

- 过渡物要在两段里都合理（猫的转头、光效、粒子、开门、甩镜）；写清过渡占比/时长
- 想让模型自由补完整情节，`duration -1` 会按输入总时长出片；也可指定 4–30s
- 这是把「各自生成好的镜头」缝成片的低成本方案；对拼接点精度要求极高时（对白接对白）仍建议后期剪辑
- 与延长的区别：延长是「一段片往后/前加新内容」；无缝转场是「两段片之间补缝」
