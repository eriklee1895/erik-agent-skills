# Skills

This directory is the canonical source for published skills.

Each direct child directory should contain a `SKILL.md` file. Keep this
directory flat, and keep skill-specific scripts, references, assets, evals,
and agent metadata inside the relevant skill directory.

Browse the categorized catalogs in
[English](../docs/skills-catalog.en.md) or
[简体中文](../docs/skills-catalog.zh-CN.md).
