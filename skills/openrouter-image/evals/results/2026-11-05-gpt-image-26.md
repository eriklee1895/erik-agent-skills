# GPT Image 2.6 evaluation — 2026-11-05

## Scope and method

An independent agent exercised 11 scenarios covering the GPT upgrade, format limits and regression paths for the other model dialects. Expected outcomes were withheld. Commands used dummy credentials and dry-run or local rejection paths.

All 11 met their decision and request-construction checks. The evaluator recorded 21 probes, comprising eight accepted dry runs and 13 expected local rejections. An explicit historical-model request was also preserved as a compatibility check.

## Verification and limits

- 80 unit and contract tests passed, including the existing Banana, Grok, MAI and batch behavior checks.
- Skill validation, relative documentation links and scoped whitespace checks passed.
- Synthetic aliases stood in for missing approved, room and style references. They support request validation; visual preservation was deferred.
- Accepted dry runs establish payload construction. Generated dimensions, copy, alpha, reference fidelity and actual cost require inspection of real provider results.
- The current GPT route accepts still-image formats. GIF, SVG and native markup restrictions remain explicit in the skill and in the evaluated responses.
