# Live Avatar 3D skill validation

Synthetic test character: a mint moth with amber leaf antennae, coral cheek
spots, a cream scarf, brown boots, and broad wings. The source and generated
images stayed in `/tmp`; no user image was used.

| Check | Result | Evidence |
| --- | --- | --- |
| GPT Image 2.5 Sunburst edit helper | Pass | One 4-view edit request; 60.802 seconds; output PNG and metadata created. Identity and major colors held; the side view simplified one antenna. |
| No-skill baseline | Fail | HTML returned 200, but the stage had no canvas. Browser error: bare module specifier `three` could not resolve from OrbitControls. Prototype also embedded the 1.51 MB source image. |
| Import map and template runtime | Pass | Three.js 0.186.0 core and addons loaded from a matching import map; one canvas; zero browser errors or console warnings after correction. |
| Core controls | Pass | Drag and arrow-key orbit, front/profile toggle, nod, shake, blink, antenna wiggle, and pause/resume were exercised. Microphone permission was not requested. |
| Narrow viewport | Pass | At 375×812, document width remained 375 px, the avatar stayed in the stage, and the title no longer overlaps the antennae. Reduced-motion emulation was detected. |
| Fresh-context application | Pass | A separate context adapted the template to custom moth geometry; front, profile, and orbit screenshots were produced with no reported page errors. Temporary output: `/tmp/live-avatar-3d-with-skill/avatar.html`. |
| Accessibility scan | Pass with manual contrast review | Axe reported 0 violations and 18 passes; 1 contrast check remained incomplete on gradient-backed text. Text colors were darkened and manually reviewed. |

The turnaround sheet is an inference aid, not a source of truth for hidden
features. The HTML template uses a CDN and requires network access; the output
has no build step or application backend.
