# GPT Image 2.6 evaluation — 2026-11-05

## Scope and method

An independent agent pass exercised all 25 current behavioral scenarios. The evaluator received the user prompts, the skill and local fixtures, with expected outcomes withheld. Commands used dry-run and dummy credentials. This evaluated routing, prompt handling, payload construction, local rejection paths and truthful reporting. Synthetic fixtures and deferred generation constrain visual acceptance checks.

Three groups covered 13 generation cases, six editing cases and six native-format cases. All 25 met their decision and request-construction checks. The groups produced 27 accepted primary dry runs, with additional rejection and sentinel probes. Case 19 correctly waited for source facts.

## Findings and corrections

- Corrected the OFOX scenario's stale expected model ID to the current Flare model.
- Moved explicit historical-caller evaluation into the history folder.
- Clarified that native batch dry-run validates structure and duplicate destinations. Live execution performs existing-image and sidecar checks before API-client construction.
- Made the GIF evidence reference's purpose explicit. One evaluator read it during a still-image case and found no additional applicable guidance.
- Fixed the SVG review finding. Six regression payloads covering stylesheet processing instructions, external base URIs, CSS animation and escaped CSS controls now fail validation. Valid XML declarations and local vector references still pass.
- Kept requested and actual GIF settings separate. The existing mismatch sample had nine distinct 512×512 frames, 200ms per frame, a 1.8-second cycle and infinite-loop metadata.

## Verification and limits

- 78 native unit, contract and SDK transport tests passed using the minimum declared OpenAI SDK, 3.46.0.
- Skill validation, relative documentation links and scoped whitespace checks passed.
- Source facts, genuine identity inputs and approval state remain required for the corresponding production tasks. Fixture substitutions were disclosed during evaluation.
- Visual fidelity, generated text, glass edges, actual latency, costs and playback quality require generated-output inspection. They were not scored by this dry-run pass.
- Earlier provider probes established successful GIF output and documented OFOX timing, markup and SVG limitations. This evaluation preserves those limits rather than asserting complete provider parity.
