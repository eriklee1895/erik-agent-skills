## Model decision

- **Flare:** preferred for ordinary generation and edits when the same acceptance bar
  is met; it was faster on both the paired generation and edit samples.
- **Sunburst:** preferred for precision-sensitive edits and when its extra detail or
  preservation is materially useful; it was slower in this run but passed the Mask,
  identity, and text-edit cases strongly.
- **Text-heavy UI/infographic work:** do not rely on a single negative instruction to
  suppress all model-generated copy. Use shorter labels, inspect visually, and finish
  publication-critical typography deterministically. Sunburst was cleaner on the
  tested infographic; neither UI output met the strict no-extra-text criterion.
- **Transparency:** native Alpha passed for both models. The visual output must still be
  checked for halos, edge color, glass/reflection treatment, and unintended shadow.
- **Editing:** prompts plus Mask produce strong local edits, but unchanged-pixel
  guarantees require deterministic compositing.

This run is a baseline, not a universal benchmark. Repeat critical text and identity
cases when changing providers, SDK versions, model snapshots, quality, dimensions, or
prompt templates.
