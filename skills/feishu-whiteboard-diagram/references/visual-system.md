# 视觉系统（文档精排）

目标气质：飞书文档里的技术说明图——可打印、可再编辑。2026-09-03 的上一版获 Human eval **Accept**；当前候选已补对比度与验证约束，完成新的飞书体验复核前不要沿用旧结论。

- **解释图（循环、分叉、对比、枢纽、时间线、泳道、四象限、焦点+细节）**：奶油底 + 4px 墨边 + `rx=0` + **一个更大的饱和焦点**。色值见 [palettes.md](palettes.md)，构图见 [composition.md](composition.md)。基准图在 [evals/fixtures/human-eval/](../evals/fixtures/human-eval/)。
- **分层条带 / 编号层级**：才用下面这套浅色分组，让每一层一种职责色。不要把这套涂到循环图上。

不是暗色监控大屏，也不是插画海报。

## 默认（解释图 · Riso Brut）

| Token | Hex | 用法 |
|---|---|---|
| cream | `#EFE9D9` | 画布 |
| ink | `#0F0F0F` | 边框、正文、默认连线、硬阴影 |
| ink-2 | `#2A2A2A` | 副标题 |
| white | `#FFFFFF` | 安静描边盒 |
| green | `#167342` | 主强调 / 成功；奶油字 4.86:1 |
| orange | `#E85A1F` | 判断、分叉、硬阴影强调；小字使用墨色 |
| yellow | `#F5C518` | 编号、点，少用 |

硬阴影：同形状副本偏移 **+10px**，无 blur。连线 `stroke-width="3"`，卡片边框 `4`。焦点必须 **比邻居大**，染色但一样大仍像草稿。其它色板（Coral / Riptide / Grove / Avocado）见 [palettes.md](palettes.md)，一张图只用一套。

## 分层条带例外（浅色分组）

未指定品牌、且图是「每一层一种职责」时用这一套。分组 2–4 个，同组节点视觉完全一致。

| 角色 | 浅底 fill | 边框 / 强调 | 用途 |
|---|---|---|---|
| 墨 | `#1F2329` | — | 标题、正文 |
| 辅助 | `#64748B` | — | 副标题、页脚说明、默认连线可改用 `#94A3B8` |
| 蓝 · 动作 / 传输 | `#EFF6FF` / `#DBEAFE` | `#2563EB` | 请求、执行、连接层 |
| 紫 · 上下文 / 会话 | `#F5F3FF` / `#EDE9FE` | `#7C3AED` | 加载上下文、复盘、会话层 |
| 橙 · 判断 | `#FFF7ED` | `#EA580C` | 菱形、决策 |
| 绿 · 产出 | `#ECFDF5` / `#DCFCE7` | `#16A34A` | 最终答案、成功态、结论条 |
| 红 · 失败 | `#FEE2E2` | `#DC2626` | failed、熔断 |
| 黄 · 中断 | `#FEF3C7` | `#D97706` | interrupted、预警 |
| 粉 · 后端 / 顶层 | `#FDF2F8` | `#DB2777` | 顶层适配、与蓝底分层区分 |
| 卡片 | `#FFFFFF` | 跟随所在分组 | 层内节点 |
| 画布 | `#F8FAFC` | `#CBD5E1` | 分层图浅底 |

色块上的字先算对比度：普通小字 ≥4.5:1，大号或粗体大字 ≥3:1。只有足够深的背景才用奶油或 `#FFFFFF`；中亮度橙/珊瑚用墨色。不要用 `opacity` 做浅色。SVG 文字用 `data-bg` 声明实际背景，交给 lint 检查。

分层图语义连线：上行蓝、下行绿。解释图的回填用焦点色 **虚线**，不要每条线都彩色。

## 字号（Noto Sans SC，无法换字体）

解释图用 [composition.md](composition.md) 的阶梯（图题 36–44）。分层条带可以略收：

| 角色 | 解释图 | 分层条带 | 字重 |
|---|---|---|---|
| 图题 | 36–44 | 28–32 | 700 |
| 区名 / 层名 | 20–24 | 18–20 | 700 |
| 卡片标题 | 18–20 | 16–18 | 700 |
| 正文 / API | 16 | 14–16 | 400 |
| 标注 | 14–16 | 14 | 500 |

同图不超过四档。不要用 12px。短标签居中，超过约 15 字左对齐。

## 间距（8 的倍数）

| Token | 解释图 | 分层条带 |
|---|---|---|
| 画布边距 | 64–80 | 48–56 |
| 标题块 → 主体 | 48–64 | 32–48 |
| 列沟槽 | 32–40 | 20–24 |
| 卡片内边距 | 20–28 | 16–24 |
| 有箭头的缝 | 48–64 | 40–56 |
| 圆角 | 默认 **0** | 层容器 16 / 内卡片 12 |
| 边框 | 4px 墨边 | 1.5–2px 色边 |
| 硬阴影偏移 | 10 | 分层图不用 |

层容器浅底 + 2px 色边；内卡片白底 + 1.5–2px 同色边。不要无边白块叠在浅底上。不要浅灰外框套均等胶囊。

## 信息层级

1. 图题：这张图叫什么。
2. 副标题：读者的问题。
3. 分区：解释图用色块尺寸；分层图用色边分组。
4. 卡片标题 + 一行技术细节。
5. 页脚结论条：读完应带走的那句话。

如果去掉颜色后分组仍能靠边框、位置和编号看出来，对比就合格。
