# 视觉系统：质量要求与可调策略

技术文档解释图需要可读、可编辑，具有清楚的阅读层级。**配色、冷暖、线宽、圆角、焦点形态与辅助区域由 agent 结合文章选择**；下面的色值与间距是起点，不绑定所有图。主题选择见 [theme-routing.md](theme-routing.md)，家族与验证状态见 [palettes.md](palettes.md)。

交付要求：事实关系准确；颜色映射稳定；文字适配目标宽度；实际前景 / 背景通过对比度检查；支持的原生结构保留可编辑性。2026-09-03 的历史整体认可不覆盖当前主题、构图或 parser；本地 PNG 与飞书体验分别记录。

| Token | Hex | 用法 |
|---|---|---|
| canvas | `#F8FAFC` | 画布 |
| surface | `#FFFFFF` | 普通卡片和节点 |
| group | `#F1F5F9` | 分组容器，不表示状态 |
| ink | `#1F2937` | 标题、正文、默认连线 |
| muted | `#475569` | 副标题、辅助说明 |

| accent-soft | `#EFF6FF` | 主分组浅底 |
| context | `#7C3AED` / `#F5F3FF` | 上下文 / 会话，需要时才启用 |

这套预置常用白卡、浅底与 1.5–2px 轻边框。根据文章可以换强调色、采用协调角色色，或选择其它家族 / 自定义方案。阴影与粗边是否需要由视觉任务决定；SVG 阴影仍遵守 [constraints.md](constraints.md) 的原生转换边界。

## 颜色角色与阅读层级

先区分颜色用于强调、职责、状态还是数据系列。`semantic-zones` 可用于分层、泳道、价值链等多种构图，不依赖用户先提供多色参考图。角色色不自动表示状态；同图需要两者时，可用浅底标角色、独立图标 / 边框标状态。

阅读层级可以由单卡、相邻区域、贯穿主线或对齐的等权方案形成。中性对比两边同大同重是合理设计，不需要制造获胜项；主论点可由标题、位置、留白与文字层级建立。多角色价值链的例子见 [semantic-columns.md](semantic-columns.md)。

下面是 Light Technical 的可选映射。换文章时可重新指定颜色含义；同图内部保持一致，并用文字与位置补足颜色信息。

| 角色 | 浅底 fill | 边框 / 强调 | 用途 |
|---|---|---|---|
| 墨 | `#1F2937` | — | 标题、正文 |
| 辅助 | `#475569` | — | 副标题、页脚说明、默认连线可改用 `#94A3B8` |
| 蓝 · 动作 / 传输 | `#EFF6FF` / `#DBEAFE` | `#2563EB` | 请求、执行、连接层 |
| 紫 · 上下文 / 会话 | `#F5F3FF` / `#EDE9FE` | `#7C3AED` | 加载上下文、复盘、会话层 |
| 橙 · 判断 | `#FFF7ED` | `#EA580C` | 菱形、决策 |
| 绿 · 产出 | `#ECFDF5` / `#DCFCE7` | `#16A34A` | 最终答案、成功态、结论条 |
| 红 · 失败 | `#FEE2E2` | `#DC2626` | failed、熔断 |
| 黄 · 中断 | `#FEF3C7` | `#D97706` | interrupted、预警 |
| 粉 · 后端 / 顶层 | `#FDF2F8` | `#DB2777` | 只有内容确实需要区分顶层适配时使用 |
| 卡片 | `#FFFFFF` | 跟随所在分组 | 层内节点 |
| 画布 | `#F8FAFC` | `#CBD5E1` | 分层图浅底 |

色块上的字先算对比度：普通小字 ≥4.5:1，大号或粗体大字 ≥3:1。浅色主题默认用墨色文字；只有足够深的背景才用奶油或 `#FFFFFF`。中亮度橙 / 珊瑚 / 状态色不要承载小字号正文。不要用 `opacity` 做浅色。SVG 文字用 `data-bg` 声明实际背景，交给 lint 检查。

连接线通常用中性或统一强调色；存在多种流向 / 系列时，可以用稳定的颜色或线型区分并写清含义。反馈可用虚线，颜色服从当前映射；角色、状态与方向不要互相混淆。

## 字号（Noto Sans SC，无法换字体）

解释图用 [composition.md](composition.md) 的阶梯（图题 36–44）。分层条带可以略收：

| 角色 | 解释图 | 分层条带 | 字重 |
|---|---|---|---|
| 图题 | 36–44 | 28–32 | 700 |
| 区名 / 层名 | 20–24 | 18–20 | 700 |
| 卡片标题 | 18–20 | 16–18 | 700 |
| 正文 / API | 16 | 14–16 | 400 |
| 标注 | 14–16 | 14 | 500 |

少量稳定字号比逐节点调整更易阅读，通常从四档左右开始。字号按真实显示宽度复核，不用缩小字来硬塞内容；短标签可居中，长说明通常左对齐。

## 间距（8 的倍数）

| Token | 解释图 | 分层条带 |
|---|---|---|
| 画布边距 | 80 | 64–80 |
| 标题块 → 主体 | 56–72 | 48–64 |
| 列沟槽 | 40 | 24–40 |
| 卡片内边距 | 24–32 | 16–24 |
| 有箭头的缝 | 48–64 | 40–56 |
| 圆角 | 12（卡片）/ 16（分组） | 层容器 16 / 内卡片 12 |
| 边框 | 1.5–2px 浅色边 | 1.5–2px 色边 |
| 硬阴影偏移 | 默认不用 | 默认不用 |

例如浅底分组可配约 2px 色边，内卡用白底与轻边界。也可以用留白、分隔线或色带组织；选择能清楚区分层级且符合文章气质的办法。

## 信息层级

1. 图题：这张图叫什么。
2. 副标题：读者的问题。
3. 主体：按关系组织分区、主线、网格或等权方案。
4. 局部标题与必要细节。
5. 辅助区域（可省略）：结论、边界、后续步骤或来源，只承载读者需要的新信息。

如果去掉颜色后分组仍能靠边框、位置和编号看出来，对比就合格。
