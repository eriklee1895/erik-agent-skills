# 视觉系统（文档精排）

目标气质：飞书文档里的技术说明图——可打印、可再编辑。2026-09-03 的上一版获 Human eval **Accept**；当前候选已补对比度与验证约束，完成新的飞书体验复核前不要沿用旧结论。

- **技术说明 / 架构图默认**：近白画布 + 白卡片 + 浅色分组 + 1.5–2px 轻边框 + 一个由尺寸和留白建立的焦点。颜色只承载明确语义。
- **编辑型解释图**：文章明确需要海报感、概念感或品牌感时，才使用奶油底 + 墨边 + 饱和焦点；色值见 [palettes.md](palettes.md)，构图见 [composition.md](composition.md)。
- **定量评测 / 基准报告**：可选 White Report 的白底橙灰数据图风格，使用细灰网格和轻分隔线；详见 [data-report-style.md](data-report-style.md)。
- **分层条带 / 编号层级 / 多列运行图**：使用下面的浅色分组；同一图最多一个主强调色，状态图才增加语义状态色。

不是暗色监控大屏，也不是插画海报。

## 默认主题（技术文档 · Light Technical）

| Token | Hex | 用法 |
|---|---|---|
| canvas | `#F8FAFC` | 画布 |
| surface | `#FFFFFF` | 普通卡片和节点 |
| group | `#F1F5F9` | 分组容器，不表示状态 |
| ink | `#1F2937` | 标题、正文、默认连线 |
| muted | `#475569` | 副标题、辅助说明 |
| border | `#CBD5E1` | 普通边框、分隔线 |
| accent | `#2563EB` | 当前主边界、请求链、焦点 |
| accent-soft | `#EFF6FF` | 主分组浅底 |
| context | `#7C3AED` / `#F5F3FF` | 上下文 / 会话，需要时才启用 |
| success | `#16A34A` / `#ECFDF5` | 成功状态 |
| warning | `#D97706` / `#FFF7ED` | 中断 / 预警状态 |
| failure | `#DC2626` / `#FEF2F2` | 失败 / 熔断状态 |

Light Technical 默认不使用硬阴影；普通卡片边框 1.5–2px，主边界或焦点可以使用 2px 色边。焦点必须 **比邻居大**，只有染色但一样大仍像草稿。硬阴影、4px 墨边和奶油底属于明确选择的编辑型主题，不得悄悄回流到技术架构默认。其它色板见 [palettes.md](palettes.md)，一张图只用一个主主题。

## 浅色分组与语义状态

Light Technical 适用于未指定品牌的大多数技术图。分组 2–4 个，同组节点视觉完全一致；如果去掉颜色后仍看不出关系，说明构图或边界还不够清楚。

| 角色 | 浅底 fill | 边框 / 强调 | 用途 |
|---|---|---|---|
| 墨 | `#1F2937` | — | 标题、正文 |
| 辅助 | `#475569` | — | 副标题、页脚说明、默认连线可改用 `#94A3B8` |
| 蓝 · 动作 / 传输 | `#EFF6FF` / `#DBEAFE` | `#2563EB` | 请求、执行、连接层 |
| 紫 · 上下文 / 会话 | `#F5F3FF` / `#EDE9FE` | `#7C3AED` | 加载上下文、复盘、会话层 |
| 橙 · 判断 | `#FFF7ED` | `#EA580C` | 菱形、决策 |
| 绿 · 产出 | `#ECFDF5` / `#DCFCE7` | `#16A34A` | 最终答案、成功态、结论条 |
| 红 · 失败 | `#FEE2E2` | `#DC2626` | failed、熔断 |
| 黄 · 中断 | `#FEF3C7` | `#D97706` | interrupted、预警 |
| 粉 · 后端 / 顶层 | `#FDF2F8` | `#DB2777` | 只有内容确实需要区分顶层适配时使用 |
| 卡片 | `#FFFFFF` | 跟随所在分组 | 层内节点 |
| 画布 | `#F8FAFC` | `#CBD5E1` | 分层图浅底 |

色块上的字先算对比度：普通小字 ≥4.5:1，大号或粗体大字 ≥3:1。浅色主题默认用墨色文字；只有足够深的背景才用奶油或 `#FFFFFF`。中亮度橙 / 珊瑚 / 状态色不要承载小字号正文。不要用 `opacity` 做浅色。SVG 文字用 `data-bg` 声明实际背景，交给 lint 检查。

分层图默认用同一主强调色表达连线；只有事实确实需要区分上行 / 下行时，才使用蓝 / 绿两种语义色，并在契约中说明。解释图的回填用焦点色 **虚线**，不要每条线都彩色。

## 字号（Noto Sans SC，无法换字体）

解释图用 [composition.md](composition.md) 的阶梯（图题 36–44）。分层条带可以略收：

| 角色 | 解释图 | 分层条带 | 字重 |
|---|---|---|---|
| 图题 | 36–44 | 28–32 | 700 |
| 区名 / 层名 | 20–24 | 18–20 | 700 |
| 卡片标题 | 18–20 | 16–18 | 700 |
| 正文 / API | 16 | 14–16 | 400 |
| 标注 | 14–16 | 14 | 500 |

同图不超过四档。不要用 12px。短标签居中，超过约 15 字左对齐。

## 间距（8 的倍数）

| Token | 解释图 | 分层条带 |
|---|---|---|
| 画布边距 | 80 | 64–80 |
| 标题块 → 主体 | 56–72 | 48–64 |
| 列沟槽 | 40 | 24–40 |
| 卡片内边距 | 24–32 | 16–24 |
| 有箭头的缝 | 48–64 | 40–56 |
| 圆角 | 12（卡片）/ 16（分组） | 层容器 16 / 内卡片 12 |
| 边框 | 1.5–2px 浅色边 | 1.5–2px 色边 |
| 硬阴影偏移 | 默认不用 | 默认不用 |

层容器浅底 + 2px 色边；内卡片白底 + 1.5–2px 同色边。不要无边白块叠在浅底上。不要浅灰外框套均等胶囊。

## 信息层级

1. 图题：这张图叫什么。
2. 副标题：读者的问题。
3. 分区：解释图用色块尺寸；分层图用色边分组。
4. 卡片标题 + 一行技术细节。
5. 页脚结论条：读完应带走的那句话。

如果去掉颜色后分组仍能靠边框、位置和编号看出来，对比就合格。
