# 视觉系统（文档精排）

目标气质：飞书文档里的技术说明图——浅色、分组清晰、可打印、可再编辑。不是暗色监控大屏，也不是插画海报。

## 色板

未指定品牌色时用这一套。分组 2–4 个，同组节点视觉完全一致。

| 角色 | 浅底 fill | 边框 / 强调 | 用途 |
|---|---|---|---|
| 墨 | `#1F2329` | — | 标题、正文 |
| 辅助 | `#64748B` | — | 副标题、页脚说明、默认连线可改用 `#94A3B8` |
| 蓝 · 动作 / 传输 | `#EFF6FF` / `#DBEAFE` | `#2563EB` | 请求、执行、连接层 |
| 紫 · 上下文 / 会话 | `#F5F3FF` / `#EDE9FE` | `#7C3AED` | 加载上下文、复盘、会话层 |
| 橙 · 判断 | `#FFF7ED` | `#EA580C` | 菱形、决策 |
| 绿 · 产出 | `#ECFDF5` / `#DCFCE7` | `#16A34A` | 最终答案、成功态、结论条 |
| 红 · 失败 | `#FEE2E2` | `#DC2626` | failed、熔断 |
| 黄 · 中断 | `#FEF3C7` | `#D97706` | interrupted、预警 |
| 粉 · 后端 / 顶层 | `#FDF2F8` | `#DB2777` | 顶层适配、与蓝底分层区分 |
| 卡片 | `#FFFFFF` | 跟随所在分组 | 层内节点 |
| 画布 | `#F8FAFC` | `#CBD5E1` | 外框（循环图、插图框） |

深色底上的字用 `#FFFFFF`，且字号 ≥ 14、字重要够粗。不要用 `opacity` 做浅色。

语义连线：上行蓝、下行绿、成功绿、回填紫虚线、默认灰。不要让每条线都彩色。

## 字号（Noto Sans SC，无法换字体）

文档插图比社区海报克制，但仍要有台阶。坐标和反套路见 [composition.md](composition.md)。

| 角色 | 字号 | 字重 |
|---|---|---|
| 图题 | 28–32 | 700 |
| 副标题 / 层名 | 18–20 | 700 |
| 卡片标题 | 16–18 | 700 |
| 正文 / API | 14–16 | 400 |
| 标注 / 页脚补充 | 14 | 500 |

同图不超过四档。不要用 12px。短标签居中，超过约 15 字左对齐。编号签（`01`）白字、粗体、14。

## 间距（8 的倍数）

| Token | 值 |
|---|---|
| 画布边距 | 48–56 |
| 标题块 → 主体 | 32–48 |
| 列沟槽 | 20–24 |
| 卡片内边距 | 16–24 |
| 有箭头的缝 | 40–56 |
| 圆角 层容器 | 16 |
| 圆角 内卡片 | 12 |
| 胶囊步骤 | `rx` 24–28 |
| 边框 | 1.5–2 |

层容器浅底 + 2px 色边；内卡片白底 + 1.5–2px 同色边。不要无边白块叠在浅底上。

## 信息层级

1. 图题：这张图叫什么。
2. 副标题或右上 callout：读者的问题。
3. 分区：用色边分组，不用靠读者数盒子。
4. 卡片标题 + 一行技术细节（`thread/start • turn/start` 这种点号列举很好用）。
5. 页脚结论条：读完应带走的那句话。

如果去掉颜色后分组仍能靠边框、位置和编号看出来，对比就合格。
