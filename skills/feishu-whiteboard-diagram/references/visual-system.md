# 视觉系统：字号、间距与颜色角色

先按 [主题选择](theme-routing.md) 决定文章气质与颜色任务；需要具体色值时查 [色板](palettes.md)。这里集中维护排版与可读性要求。表中数值是起点，按内容、显示宽度和既有视觉身份调整。

## 颜色承担什么

区分颜色用于强调、职责、状态还是数据系列。同一角色内部保持一致；同时表达角色与状态时，可用浅底标角色、独立标记或边框标状态。文字与位置应足以解释关系，不让读者只靠颜色猜。

阅读重心可以是单卡、相邻区域、贯穿主线或等权方案。协调多色适合职责区分，中性色适合等权比较；颜色数量由任务决定。参考 [构图选型](composition.md) 和 [语义分区](semantic-columns.md)。

## 对比度

- 普通文字至少 4.5:1；≥24px 或 ≥19px 且字重 700 的大字至少 3:1。
- 浅色背景通常配深墨色正文；深色块上的浅字按实际前景 / 背景计算。中亮度橙、珊瑚或状态色上的小字尤其需要复核。
- 用实心浅色表达浅底，不依赖 `opacity`。文字标注实际 `data-bg`；没有标注的配对不在 lint 的对比度覆盖范围内。
- 背景、字号或字重变化后重新计算。预置色板的配对通过，不代表整张图或改编后的配色通过。

## 字号起点

画板字体以底座当前实现为准，本 skill 不设置 `font-family`。少量稳定字号比逐节点调整更易阅读；短标签可居中，长说明通常左对齐。

| 角色 | 解释图 | 紧凑分层图 | 字重 |
|---|---|---|---|
| 图题 | 36–44 | 28–32 | 700 |
| 区名 / 层名 | 20–24 | 18–20 | 700 |
| 卡片标题 | 18–20 | 16–18 | 700 |
| 正文 / API | 16–22 | 14–18 | 400 |
| 标注 | 14–20 | 14–18 | 400–500 |

这些是逻辑坐标字号，不是最终显示字号：`显示字号 ≈ SVG 字号 × 显示宽度 / viewBox 宽度`。例如 1600px 宽图缩到 800px 时，16px 字只剩约 8px。根据预期正文宽度提高字号、减少内容或拆图；如果交付的是需点开阅读的细节板，应明确其阅读方式。放大 PNG 可读不能证明文档默认宽度可读。

## 间距起点

| Token | 解释图 | 紧凑分层图 |
|---|---|---|
| 画布边距 | 80 | 64–80 |
| 标题块 → 主体 | 56–72 | 48–64 |
| 同排沟槽 | 40 | 24–40 |
| 卡片内边距 | 24–32 | 16–24 |
| 有箭头的通道 | 48–64，标签较长时加宽 | 40–56，按接口文字调整 |
| 圆角 | 卡片 12 / 分组 16 | 卡片 12 / 分组 16 |
| 轻边框 | 1.5–2px | 1.5–2px |

8px 节奏便于建立共同栅格；它不要求所有尺寸都是 8 的倍数。容器按最长文字和走线预算确定，重复卡复用共同边缘、文字起点与内部节奏。选择粗边或硬阴影时，按当前主题调整并检查有意重叠，SVG 支持边界见 [介质约束](constraints.md)。

## 图中保留什么

图题说明问题；主体表达关系；局部标题与说明支撑阅读。辅助区域按需放结论、边界、来源或下一步，内容与主图有明确联系即可，不要求固定副标题或页脚。

来源、样本、模型 / 协议版本若影响理解或复算，应保留。生成过程、工具版本、提示词和本地路径放在交付记录中。跨图的共享视觉约定见 [成套技术图](technical-article-figures.md)。
