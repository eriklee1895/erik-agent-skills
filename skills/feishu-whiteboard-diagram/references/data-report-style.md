# 定量报告规则与可选白页橙灰风格

适用于来源明确、指标精简、读者需要快速看出差异和结论的静态模型评测、基准测试、质量 / 延迟 / 成本对比。尺度、单位、计算与系列语义是通用要求；白页橙灰只是一个可选表现，可按品牌或文章使用其它预置及自定义配色。需要动态筛选或交互探索时改用 HTML5。

## 白页橙灰示例的视觉语言

- 白色画布，深色标题与正文；候选系列用暖橙，基线系列用浅灰。系列颜色在标题图例、条形和标签中保持一致。
- 标题靠左，下面用一行灰色副标题交代对比对象、样本或指标口径；图例放在标题区右侧。橙色短线或小圆点可作为标题记号，选一种即可。
- 用浅灰细网格线和分隔线组织信息。确实需要分组时，使用白底、细浅灰边的圆角面板；不用粗黑边、硬阴影或大面积灰框。
- 条形可以有小圆角，但保持为图表而不是按钮胶囊。留足页边距，数值、单位、刻度、行标签和差值标记不要互相挤压。
- 页脚可写来源、样本量、时间或估算口径，但只写来源材料中有依据的信息。不要复制参考图的水印、模型名、数据或结论。

具体颜色值见 [色板](palettes.md) 的 **White Report**。使用这个预置时，小字号橙色文字用深橙文字色，橙条内小字用深色。改用品牌青色等其它方案时，重新指定系列、基线、强调和文字配对；保留下面的版式及数据规则，逐项计算实际对比度。

## 按问题选择版式

| 要回答的问题 | 版式 | 关键做法 |
|---|---|---|
| 实验或分析是怎样推进的？ | 单行编号流程 | 横向排列少量步骤，用轻量灰线连接；普通步骤保持安静，只突出关键评估 / 决策步骤。终点节点只有在确为选出的结果时才用强调色。 |
| 多个任务的质量指标差多少？ | 并排任务面板 | 每个任务一个面板；指标按行排列，每行用灰 / 橙配对横条，旁边标数值和差值。可在面板底部留一句该任务的摘要。 |
| 大样本评测的质量与业务结果如何？ | 主图 + 结论卡片 | 左侧用一张较大的指标图说明质量差异，右侧用少量卡片呈现成本或关键结果。最重要的一项可以使用浅橙底和大数字，其余卡片降一级。 |
| 时间和费用分别差多少？ | 双指标面板 | 时间、费用各用自己的面板、单位和坐标轴；两个量纲不可共用刻度。系列颜色固定，突出节省比例或比值，并保留估算 / 实测口径。 |
| 文章开篇需要先看结论，再核对多项证据？ | 摘要指标 + 证据面板 | 上方少量大数字给出各自范围与口径；下方按指标族分面板验证。长类别标签可用横条，少量短类别可用分组柱；平台 / 系列映射在面板间保持一致。 |

以上是可选版式，不要把它们拼成一张固定仪表盘。只保留能直接回答当前问题的面板和注释；内容过密时拆图，不缩小文字硬塞。

## 数据标注规则

- 先确认比较对象、基线、样本范围、单位和“越大 / 越小越好”的方向，再决定颜色与结论。颜色标识系列或强调，不自动代表优劣；白页橙灰示例中的橙色也遵守此规则。
- 同一种指标使用同一尺度；精确率、召回率等百分比指标默认用完整 `0–100%` 范围。不要为放大差异而截断坐标轴。不同单位（如秒和美元）分别设轴。
- 百分比指标的绝对差写百分点 `pp`，计算为 `候选值 - 基线值`；相对增减用 `%`，应明确计算口径。例如降低比例为 `(基线值 - 候选值) / 基线值 × 100%`。倍数标注说明谁是分子、谁是分母。
- 数字精度和舍入方式在同一图内保持一致。差值、比例、倍数必须能由来源数据复算；若来源精度不足，就降低标注精度或省略推算。
- 不用颜色代替含义：正负值、性能好坏、风险和置信度靠文字或明确图例说明。可按系列数使用多种协调颜色；出现状态 / 风险标记时说明其含义，避免与系列色冲突。
- 图例说明颜色对应谁；坐标刻度说明范围；小标题或脚注说明单位和估算口径。避免让读者从上下文猜单位。

## 摘要指标必须能回到证据面板

- 每张大数字卡保留「指标名称 + 变化口径 + 适用范围」。例如端 A / 端 B、均值 / P90、总体 / 子集、最大值 / 典型值不能互换；只在某端出现的最大改善不能写成全体用户的普遍收益。
- 摘要数字能在下方找到对应项或由基线复算。来源只给相对变化时，可以画变化图，不倒推未给出的绝对值或样本量。
- 正负变化与“下降幅度”选择一种轴口径。画带符号变化时，负数向负方向延伸；画下降幅度时，轴与标签都用非负幅度，并明确“下降”。不把负刻度按正向长度排列。
- 数值准确还要校验几何：柱长按同一个零点和比例计算，网格刻度与条形绘图区共享起点、终点。先定标签区宽度再定数据零点，不能让类别标签挤出条形零点后，仍沿用旧网格。

## 飞书 SVG 落地

按主 skill 的 SVG 约束绘制：条形和面板用可识别的原生形状，标签用 `<text>`，网格和分隔线用 `<line>`。不要把文字转路径或把整图烘焙成图片；保留可编辑节点，并遵循当前 parser-contract、`lint_svg.py` 与官方 `lark-whiteboard` 限制。不同元素的支持能力以底座和本 skill 的介质约束为准。
