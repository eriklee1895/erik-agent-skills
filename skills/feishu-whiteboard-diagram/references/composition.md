# 构图：按阅读任务建立层级

构图由实体与关系决定，配色由文章气质、品牌和颜色角色共同决定。两者可以独立选择：同一构图可以用不同家族，同一色板也可服务不同图。参考 [选择方法](theme-routing.md)、[视觉系统](visual-system.md) 和 [配色家族](palettes.md)。

原型提供可调整的空间关系，不要求每张图有唯一最大卡、唯一饱和块或固定页脚。下面的参数用于起步；实际文字、目标文档宽度和来源关系决定最终尺寸。

## 间距（8 的倍数）

| Token | 值 |
|---|---|
| 画布边距 | 80 |
| 标题块 → 主体 | 56–72 |
| 列沟槽 | 40 |
| 卡片内边距 | 24–32 |
| 有箭头的缝 | 48–64 |
| 硬阴影偏移 | 默认不用；编辑型主题 10 |

可以通过留白、浅色分组、轻边界或分隔线组织层级。需要编辑感时可增加粗边和实心硬阴影；报告图通常降低装饰以便比较。保持同图的线宽、圆角和间距节奏一致。

## 字号

| 角色 | 字号 | 字重 |
|---|---|---|
| 图题 | 36–44 | 700 |
| 区名 | 20–24 | 700 |
| 卡片标题 | 18–20 | 700 |
| 正文 | 16 | 400 |
| 标注 | 14–16 | 500 |

浅色主题默认使用墨色文字；深色块上的字用奶油或白，且够大。不要 12px。

## 阅读层级

先说明读者的视线路径，再决定强调方式：

| 阅读任务 | 可用层级 |
|---|---|
| 一个关键判断 | 用尺寸、位置、留白、字重或色块突出；不要求所有手段同时使用 |
| 相邻两层共同解释论点 | 把两列组织成连续的阅读区域，两端降一级 |
| 系统流动与反馈 | 让主线和独立走线通道组织阅读，而非强行放大某张卡 |
| 中性比较 | 方案等宽、等重、行对齐；没有来源结论就不设获胜项 |
| 有来源支持的结论 | 突出结果或相关证据，保留其他选项可读性 |

单卡焦点、复合区域与等权比较都通过“读者能否快速找到问题和比较关系”复核。颜色数量不替代结构判断。

## 密度与删减

多角色价值链可参考 [semantic-columns.md](semantic-columns.md) 的复合区域和走线预算；同样的层级方法也可用于其它关系。

- 默认不超过 12 个主信息块；更多内容拆成总览和细节图。
- 正文已经清楚表达、且布局本身能说明的关系，不再补箭头或图例。
- 辅助区域按内容选择结论、边界、步骤或来源，也可以省略。来源没有给出顺序的建议保持并列，不补造实施依赖；重复标题或正文导语的内容删除。
- 不用缩小到 12px 换取“完整”。读者任务优先于把所有材料塞进一张图。

## 原型（从社区样板收）

按关系选，不要默认画胶囊流程图。

| 关系 | 原型 | 可选强调方式 |
|---|---|---|
| X 然后 Y，中途分叉再汇合 | 流水线 + 分叉 | 分叉可扩大或增加留白，准备步骤保持较轻 |
| 谁决策 / 谁执行 | 流水线 + 分叉，判断形状保证文字可读 | 工具回路可作为区域重心；直接回答是短支 |
| 三选一、权衡 | 对比列 | 中性比较等权；有来源结论时再突出相关格 |
| 有基线和候选值的定量评测 | 配对横条或主图 + 结论卡 | 同尺度指标成对比较；时间和成本分别使用各自坐标轴，详见 [data-report-style.md](data-report-style.md) |
| 一个核心带 N 个方面 | 枢纽 + 卫星 | 核心位置与连接关系清楚，尺寸按信息量调整 |
| 阶段 / 里程碑 | 时间线 | 关键阶段可强调；没有高潮时保持连续节奏 |
| 层 / 协议 | 分层条带 | 当前要讲的层略高 |
| 多角色握手 | 泳道 | 角色区分清楚；可按角色浅色分组 |
| 两个维度、四个去处 | 四象限 | 四区可等大；来源明确的重点用标记或局部强调 |
| 一个主判断 + 若干支持点 | 焦点+细节 | 左侧大卡 1.5–2× 右侧支持 |
| 值不值得写回去 | 上门禁 + 下面三列对比 | 三种落盘写满对比项，不是箭头迷宫 |

## 复核常见问题

- 重复节点的视觉权重是否符合真实关系？等权比较允许等大，存在差异时应让文字与结构说明差异。
- 反馈线路是否有明确含义、独立通道且不穿过文字？无意义的绕场线与空壳容器应删除。
- 颜色、边框、背景是否形成同一个视觉系统？取自不同家族的颜色也要重新检查搭配。
- 卡片、判断、连线是否满足当前介质与文字适配，而非为了风格丢失可编辑性？
- 图中只放读者需要的内容，不放任务提示或色板名称。
