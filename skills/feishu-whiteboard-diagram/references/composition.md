# 构图（文档精排，不是海报）

色板见 [visual-system.md](visual-system.md)。本页回答「东西放哪、谁最大」。社区
`beautiful-feishu-whiteboard` / `feishu-whiteboard-pro` 的价值在这里：35 套色板可以不搬，
**间距、字号阶梯、焦点靠尺寸、反均等卡片**必须吸收。本 skill 默认仍是技术文档插图，
不用 64px 海报大字，也不做换肤目录。

## 间距（8 的倍数）

| Token | 文档插图 | 不要 |
|---|---|---|
| 画布边距 | 48–56 | 内容贴边，或 80px 边距把图掏空 |
| 标题块 → 主体 | 32–48 | 标题和第一排卡片隔一座峡谷 |
| 列沟槽 | 20–24 | 列与列之间大片空白 |
| 卡片内边距 | 16–24 | 字贴边，或卡片 80% 空 |
| 有箭头的缝 | 40–56 | 线绕整张画布走一圈才回到起点 |

内容带宽大约 `x ∈ [48, 1472]`。高度跟内容走；上下两排卡片之间不要留一整块空壳。

节奏：焦点区域多留气，次要簇收紧。均等 padding 会看起来像模板。

## 字号（Noto Sans SC，无法换字体）

层次靠 **尺寸 + 字重**，相邻档至少差一档。文档插图比社区海报克制，但仍要有台阶：

| 角色 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 图题 | 28–32 | 700 | 每张图一个 |
| 区名 / 层名 | 18–20 | 700 | 列头、条带名 |
| 卡片标题 | 16–18 | 700 | 节点主文案 |
| 正文 / API | 14–16 | 400 | 技术细节 |
| 标注 | 14 | 500 | 是/否、回填；不要 12 |

深色底上的字 ≥ 16、够粗。不要靠 `opacity` 做浅色。

## 焦点靠尺寸，不只靠颜色

蹲下来（或眯眼）必须先看到一件东西。染色但和邻居一样大，不算焦点。

- 任务循环：最大的是 **判断**，其次是 **最终答案**；工具回路收进一条矮带。
- 学习闭环：最大的是 **值得复用?**；「结束」要小；三种落盘是同等次级。
- 多列运行：最大的是 **运行时 / Agent Loop** 那一列；不要四列等高同宽。
- 分层 / 编号层级：当前要讲的那一层可以略高，其余层矮一截。

## 五种语法怎么落位

骨架仍以 [grammars.md](grammars.md) 的关系为准，坐标只保证密度：

1. **分层条带**：满宽横带，层内三列对齐。层间用短 API 箭头，不要装饰带。
2. **任务循环**：上排主路径，下排一条 **矮的工具带**；虚线从工具结果接到判断底边，不要绕外框。
3. **学习闭环**：判断在上排居中偏大；门禁文案写在门禁卡片里；落盘三卡成一条；「下一轮」短虚线回任务完成。
4. **多列运行**：列壳包住「上请求 / 下事件」两张卡，中间只留箭头缝。不要先画 560 高的空列再把卡片贴在顶和底。
5. **编号层级**：01 签压边框；右侧问题列；层间一句包含关系。

## 反套路（画完过一遍）

- **均等卡片栅格**：N 个一样大的圆角矩形。有焦点就放大它，其余缩小。
- **绕场虚线**：回填/下一轮沿着画板外框走一圈。改成最短正交折线。
- **空列壳**：列容器比内容高一倍。列高跟着两排卡片走。
- **图内图例当结论**：页脚写读者该带走的话，不要只写「蓝=动作」。
- **居中堆砌**：标题和主文案默认左对齐；只有真正的枢纽才居中。
- **装饰编号 / 彩条**：`01` 必须表示顺序或层级，否则删掉。
- **把用户任务或风格名写上画布**：禁止。

Mermaid 时序、类图、饼图、甘特：**不要用上面的语法重画**。写成 `<whiteboard type="mermaid">`，飞书服务端自己转成画板。
