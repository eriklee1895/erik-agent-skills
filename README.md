# erik-agent-skills

![Erik Lee Agent Skills README banner](assets/erik-agent-skills-cover-wide.png)

Erik's personal Agent Skills repository.

## Repository role

- `skills/` is the canonical source and publishing directory.
- Skills are curated here for cross-project and cross-agent reuse.

Each skill is a self-contained directory with a `SKILL.md` file and optional
`scripts/`, `references/`, and `assets/`.

## Status

The repository currently includes an initial seed set of 23 writing skills.

## Companion repository

Explore [writing-agent-harness](https://github.com/eriklee1895/writing-agent-harness),
Erik's personal AI writing system for ideation, research, drafting, polishing,
visuals, publishing, and continuous workflow improvement.
